Keep the riff going.

A riff is a short phrase one player starts and the next picks up. Riffet is a self-hosted workbench that keeps work with coding agents that way: read it, step in, and pick it up on any screen.

$ npm install -g riffet

Plugins

Extend model sources, views, commands and palettes with plugins. The canvas is implemented as one. Browse plugins

$ riffet plugin dev ./my-plugin
$ riffet plugin pack ./my-plugin --out my-plugin.tgz
$ riffet plugin install my-plugin.tgz

Start

$ npm install -g riffet
$ riffet start --workspace .
$ riffet pair   # a code and a QR for your other devices

Code, terminals and credentials remain on your machine. No account, no cloud relay.
