# 简报

简报回答一个问题：用户现在需要知道什么、需要做什么。不是活动流水账。

## 收集

1. `task_list`：等用户回答的、等验收的、进行中的、最近完成的。
2. `session_list`：`waiting` 和 `failed` 的会话；需要时用 `session_read` 看它停在哪里。
3. `list_wakeups`：今天和明天到期的提醒。
4. 记忆里带日期的承诺和日程（读对应的主题文件）。
5. 上次简报之后才发生的事才写。上次简报的时间从这个对话里找（`history_search`，`session: "self"`）。

## 写法

按这个顺序，没有内容的部分整段省略：

1. **要你处理**：等回答的问题、等验收的交付、出错的会话。每条一行，带任务编号或会话标题，说清要用户做什么。
2. **今天的安排**：到期的提醒和带日期的承诺。
3. **进行中**：一行一件，只写状态有变化的。
4. **已完成**：只列标题。

- 全部加起来不超过十几行。什么都没有就说「没有需要你处理的事」，不要凑内容。
- 不复述交付内容，不解释任务背景，用户自己知道。

## 定期简报

用户要每天或每周的简报时，按 `riffet:reminders` 里周期性的做法安排唤醒。到点后把简报写在这个对话里，并用 `notify_user` 发一句话的摘要，例如「2 件事等你处理，今天 15:00 有组会」。
