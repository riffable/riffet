The VT engine in src/commonMain/kotlin/riffet/terminal/ is a Kotlin port of the
terminal-emulator module of Termux (https://github.com/termux/termux-app), taken at commit
8629e632fcb95da272221be327db653fb24befe9. That module is licensed under the Apache License,
Version 2.0 (the rest of the Termux repository is GPLv3 and none of it is used here); it in turn
derives from Jack Palevich's Android Terminal Emulator, also Apache-2.0.

Changes from the original:
- translated from Java to Kotlin common code (no java.*, android.* or JNI);
- the image protocols (Sixel, iTerm2 inline images, terminal bitmaps) are not ported;
- TerminalSession, ByteQueue and the local PTY are not ported: the engine is fed bytes from a
  WebSocket instead of a forked shell;
- TerminalSessionClient is reduced to the cursor and logging callbacks the engine calls;
- TerminalRow.setChar gives both columns of a wide character one style, and removes the
  combining characters of a column a wide character overwrites;
- TerminalEmulator.encodePaste returns what paste() writes;
- WcWidth keeps a table of every BMP code point's width;
- TerminalRow.clearFrom / copyAllFrom: whole-row fast paths for TerminalBuffer.blockSet /
  blockCopy, equivalent to upstream's per-cell loops but linear instead of quadratic.

Unit tests in src/commonTest/kotlin/riffet/terminal/ are ported from the same commit.
