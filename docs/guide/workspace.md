## 工作区与变更

项目使用真实的本地绝对路径。文件树、文件名搜索和内容搜索限定在项目范围内；项目内的路径仍会检查符号链接，指向项目外的符号链接不能通过文件 API 读取。

只读预览、单文件引用和编辑器跳转对**项目外的显式绝对路径**是放行的：Agent 经常在 `/tmp` 之类的地方产出截图或临时文件，机主理应能看一眼。这条通路刻意保持狭窄——路径必须是绝对路径、必须已存在、必须是常规文件，没有目录列举、没有搜索。未设置时它跟随监听地址：只监听本机时开启，监听局域网时关闭；「设置 → 文件与编辑器」可以显式开关。无论开关如何，工作台数据目录（令牌、Cookie 密钥、后端 API Key）、`~/.ssh`、`~/.gnupg`、`~/.aws` 等凭证目录、各 CLI 的认证文件，以及 `.env*`、`id_*`、`*.pem`/`*.key` 这类文件都拒绝读取，经符号链接指向它们也一样。代码引用在服务端重新读取，附加到 Agent 提示中。

「添加项目」里的「浏览…」会唤起**服务所在 Mac** 的系统目录选择器（Finder），因为浏览器无法自行取得本地绝对路径。非 macOS 主机、选择器不可用或启动失败时会自动回退到内置的目录浏览器；用户在选择器里点取消则什么都不会发生。局域网访问时，选择器同样出现在服务器那台机器上。

图片、文本、压缩包、Office 文档和其它普通文件都可以作为附件上传，不设格式白名单。单文件上限为 24 MiB，每条消息最多 20 个附件；超限整批拒绝并给出原因。未知格式使用通用二进制 MIME，保留原文件名和原始字节。发送时，图片按后端图片协议处理，其它文件按文件引用或保留原文件名的本地路径交给 Agent，由 Agent 调用工具读取、解压或解析；上传本身不展开压缩包，也不把二进制转成提示词文本。已发送的附件会显示在用户消息下方：图片按缩略图渲染（点击打开原图），其它文件显示可下载的文件名胶囊，刷新或重开会话后仍可通过附件元数据恢复。网页、Android 和 macOS 支持通用文件；iOS 的系统附件选择器尚未实现。用户消息下方还有一条 `M/D HH:MM` 时间戳，悬停可看完整时间；回答下方同样有一条（与复制按钮同一行，时间戳常显、复制按钮悬停出现）。IDE 跳转在服务所在的 Mac 上执行，可在设置中配置 `code --goto`、`cursor --goto` 或现有编辑器命令。

对话里的文件入口以「就地预览」为主：工具行上的 `path:line` 标签、Diff 头部的文件名点击后会在右侧上下文面板直接打开该文件（行号会滚动到视野中央并短暂高亮），而不是离开工作台跳编辑器。每个标签右侧悬停出现的外部链接按钮仍然调用 IDE 跳转，上下文面板预览头部也保留「在编辑器中打开」按钮。

文件面板直接预览 PNG、JPEG、GIF、WebP、AVIF 和 BMP 图片，按文件内容识别格式，大小上限为 24 MiB。SVG、ICO、TIFF、HEIC / HEIF 走隔离预览或图片转换，保留原始文件下载。图片读取沿用单文件预览的项目范围和项目外绝对路径设置。

文件面板与普通附件共用本地预览，文本文件保留源码切换，指定行号时优先显示源码：

| 格式 | 预览内容 |
| --- | --- |
| Markdown / MDX | 静态阅读、GFM 表格、数学公式、本地图片、按当前主题选择的 `<picture>` 图片与图表围栏；内嵌 HTML 经过过滤，不执行 MDX 组件 |
| PDF | 分页画面与可选择文字，最多预览前 200 页；密码文件需下载后打开 |
| DOCX、ODT、RTF、EPUB、TeX | 文本、标题、表格、图片、公式等静态内容；服务器装有 LibreOffice 时 DOCX、ODT、RTF 按原排版分页显示 |
| PPTX、ODP、ODG | 按文档顺序阅读页面内容，不播放动画或宏；有 LibreOffice 时按幻灯片分页显示 |
| DOC、PPT、PPS | 只在服务器装有 LibreOffice 时预览，转为 PDF 后分页显示；否则作为二进制文件下载 |
| XLSX、XLS、XLSB、ODS、CSV、TSV | 切换工作表、查看缓存值；最多 12 表、每表 1,000 行 / 100 列、合计 100,000 单元格，不计算公式 |
| JSON、JSONL、YAML、TOML、XML | 可展开的结构视图；XML 不读取 DTD / 实体 |
| Jupyter Notebook | Markdown、代码与已保存的文字 / 表格 / 图片输出，不执行代码或 widget |
| Mermaid、DOT、PlantUML、D2、Vega / Vega-Lite | 本地渲染图表，随当前配色更新 |
| 音视频 | 系统 WebView / 浏览器能够解码的音视频，带播放控件；按字节范围流式读取，不受 32 MiB 上限约束，可以拖动进度 |
| ZIP、TAR、GZ、TGZ | 文件清单或解压后的文本，不向磁盘展开归档 |
| SQLite | 只读快照中常规数据表的前 200 行，最多 100 表；不执行视图或虚拟表 |
| GLB、GLTF、OBJ、STL、PLY | 可旋转、缩放的模型；GLTF 资源需内嵌，未接入 Draco / KTX2 / meshopt 解码器 |
| TTF、OTF、WOFF、WOFF2 | 字体样张，可在样张内临时输入文字 |

**LibreOffice 是可选的**：Riffet 不安装它；服务启动后第一次用到时按 `RIFFET_SOFFICE`、`PATH`、`/Applications/LibreOffice.app` 的顺序找 `soffice`（装好后要重启服务，`riffet doctor` 的 Server 一节显示是否找到）。文档转换一次只跑一个，每次用独立的配置目录，超过 `FILE_BUDGET.officeConvertMs` 被杀掉，转好的 PDF 在内存里按内容缓存（`officePdfCacheBytes`）；转换失败时退回上面的文本阅读。表格不走 LibreOffice，保留可切换工作表的网格（`apps/server/src/previews/office-convert.ts`）。

任何文件都可以从预览的「⋯」里「以十六进制查看」，二进制文件的空状态里也有这个入口：按 `FILE_BUDGET.hexPageBytes` 分页经字节范围读取，只读当前看到的部分，与文件大小无关。文本文件可以「查看末尾」：读最后 `FILE_BUDGET.tailBytes`，从完整的一行开始；超过 32 MiB 的文本直接以这种方式打开。末尾视图里打开「跟随」后每 `followMs` 读一次新写入的部分，面板不可见时暂停，适合看日志。

渲染后的 Markdown、文档、表格、PDF 等预览里选中文字，选区上方出现「引用」，把这段文字连同文件路径作为引用放进当前会话的输入框（会话的输入框不在屏幕上时改为引用整个文件）；新会话页上没有这个按钮。预览页只把选中的文字和位置告诉面板，面板只接受来自这个预览框的消息。

共享预览单文件上限为 32 MiB（音视频除外），服务端解析有 12 秒与内存预算；超限或解析失败时仍可下载。普通文本兼容 UTF-8、带 BOM 的 UTF-16 与常见 GB18030 / GBK 编码。macOS 与 iOS 另保留系统 Quick Look，具体格式由系统及已安装插件决定；旧版 DOC / PPT、RAR / 7z、加密归档和专业设计文件不承诺通用内嵌渲染。Office 内容为静态阅读转换，复杂排版可能与原应用不同。

文件可以下载。文件面板每一行悬停出现「⋯」，右键同样打开：文件可引用、下载、在新标签页打开、在编辑器中打开，文件夹可打包成 ZIP 下载，两者都能复制相对或绝对路径。面板顶部的下载按钮打包当前文件夹（在根目录即整个项目）；预览头部有下载按钮，「⋯」里还有在新标签页打开、复制文件内容和复制路径；二进制文件显示下载入口。对话里的 `path:line` 标签和 Diff 头部悬停出现复制路径与下载按钮；回复里指向本地文件的 Markdown 链接（绝对路径、相对项目根目录的路径、`file://`，可带 `#L12` 或 `:12`）点击在右侧预览，Cmd/Ctrl/中键点击在新标签页打开原文件。

单文件下载不限大小，流式读取，读取范围与预览相同（含可关闭的项目外绝对路径）。在新标签页打开时，PDF、图片、音视频和文本直接显示，HTML 按页面渲染，其余类型直接下载；打开的 HTML 运行在沙箱的独立源里，拿不到工作台的登录态。

面板中的 HTML 默认按页面渲染，预览与源码之间可以切换。项目里的 HTML 以所在文件夹为站点根：同目录及子目录的样式、脚本、图片与页面链接按相对路径加载，点击链接在面板内跳转，面板顶部的路径随之更新。页面运行在沙箱的独立源里，凭路径中限时的只读令牌访问这个文件夹（随签发它的登录或设备失效，最长约 13 小时；过期后面板自动换新令牌重开当前页），拿不到工作台的登录态；以 `.` 开头的路径和密钥类文件不对页面开放，文件夹之外（`../`）也不行；项目外的 HTML 文件沿用单文件只读，只开放它自己，相对资源不加载。共享生成页在独立源中显示，仅使用内联脚本、样式与内嵌资源，不能读取工作台存储、登录态或 API。Markdown 的本地图片由服务端逐个检查读取范围，再嵌入预览。

项目 Markdown 的相对图片路径以该文件所在目录为基准。上传的 Markdown 附件没有原目录，引用另一张已上传图片时使用 `![说明](attachment:<附件 ID>)`；远程图片不会加载。预览最多内嵌 24 张、合计 16 MiB 的本地图片，生成页面上限为 32 MiB。

### 编辑与文件操作

项目内的 UTF-8 文本文件可以在文件视图里编辑，也可以新建、改名、移动和删除文件或文件夹（`apps/server/src/workspace/write.ts`）。主要的改动由 Agent 做，这里是给人顺手改一处用的，所以只编辑整份读进预览的文件（`FILE_BUDGET.previewTextBytes`），GB18030、UTF-16 等其他编码只读。

- **写入范围**比读取更窄：只在项目内，不能写项目目录本身和 `.git` 里的任何文件（那里的 hook 会在下一次提交时执行），工作台数据目录和凭证目录同样拒绝；没有项目外的通路，「允许预览项目外的文件」不影响写入。
- **保存带版本**：保存时带上打开时的 `hash`，文件已经被别人（通常是 Agent）改过就返回 409 `FILE_CHANGED`，磁盘上的内容不动，客户端读取当前内容让用户比较。同一文件的保存在服务端排队，版本检查与写入不会和另一次保存交错。
- **写入是原子的**：先在同目录写临时文件并落盘，再改名覆盖原文件，中途失败原文件完好；保留文件权限、UTF-8 BOM，整份用 `\r\n` 的文件保持 `\r\n`。改名覆盖会断开硬链接；符号链接写到它指向的文件。
- **不记到 Agent 名下**：工作台的写入登记为编辑（`workspace-observer.ts#noteEdit`），同时在跑的 shell 命令不会把这个文件算进自己的「产出」。
- **删除可撤销**：删除的文件或文件夹移到状态目录的 `file-trash/`，24 小时内可以撤销（`FILE_BUDGET.trashRetentionMs`），总量超过 `trashBytes` 时先清最旧的；单次超过 `trashItemBytes` 的删除返回 409 `DELETE_UNRECOVERABLE`，客户端确认后再永久删除。服务启动和每次删除时清理。

接口：`PUT /api/projects/:id/file`（保存）、`POST .../file/create`、`.../file/move`、`.../file/delete`、`.../file/restore`。服务端声明 `file-write-v1`，没有这个特性的服务器不显示编辑入口。

#### 多服务器

1. 项目文件是 A 类工作对象，存在项目所在的服务器上。
2. 文件不进合并列表；打开、保存、删除都发往项目所在的服务器，对端离线时预览和编辑入口不可用，未保存的修改留在客户端，恢复连接后再保存。
3. 新路由都只处理本机项目的文件，链接声明为 `serve`。
4. 客户端经按服务器选目标的请求层发请求，未保存的修改以（服务器、项目、路径）区分。
5. 不新增对象 id；回收区的 `restoreId` 只在所在服务器有效。
6. 不涉及扩展点（文件查看器扩展点另行设计，作用范围为 `object`）。
7. 不新增助理或 Riffet MCP 工具。
8. 入口不缓存对端文件内容。
9. 不发提醒。
10. 对端没有 `file-write-v1` 时按只读处理。
11. 不涉及对端的控制权。

文件夹打包限定在项目内：在 Git 工作区里只包含 Git 会显示的文件（已跟踪的，以及未跟踪且未被忽略的），与 `git archive`、代码托管平台的「下载 ZIP」一致；不在 Git 中时跳过符号链接和 `node_modules`、`.git`、`dist`、`build` 等目录。上限为 2 万个文件或 2 GiB，超出时提示而不是下载一个不完整的包。

预览带按行语法高亮：`apps/web/src/lib/highlight.ts` 按扩展名映射到 Prism 语法（ts/tsx/js/jsx/json/yaml/toml/bash/css/scss/less/html/xml/svg/vue/svelte/sql/md/py/go/rs/java/kt/swift/c/cpp/rb/php/cs），用 `refractor` 在 hast 层按换行切分，因此块注释、模板字符串这类跨行 token 在每一行都能保持闭合标签。高亮器和各语言语法全部通过动态 `import()` 懒加载，各自独立成 chunk，不进入首屏包；语言未知、加载失败或抛错时立即回退为纯文本。`.vue`/`.svelte` 没有专属语法，按 HTML 高亮，`<script>`/`<style>` 内不切换语言。

Git 面板提供状态、工作区与暂存区 Diff、暂存、取消暂存、丢弃和提交。暂存、取消暂存与丢弃既可以对整个文件，也可以对 Diff 里的单个改动块；改动块操作带着读取 Diff 时的内容版本，文件在此期间变化会被拒绝并重新读取。丢弃前先把涉及的文件存成一个只包含这些文件的检查点，撤销就是恢复它，其余文件不受影响；无法保存的文件（如超出容量限制）需要确认后才会丢弃。改动列表除 Uncommitted（未提交的改动）外，还可以切换为 This Turn（相对本回合开始前的 Checkpoint）和 Branch（相对离开主线处）两个范围。History 页显示 Commit 图（当前 Branch 或全部 Branch、Tag），选中一个 Commit 可以看它的说明、改动的文件和每个文件的 Diff；同一页可以切换或新建 Branch、Fetch。落后上游时发布区提供 Pull，只做 fast-forward，本地与远端各有新 Commit 时拒绝。切换 Branch 和 Pull 会改写工作区文件，有回合在运行时不执行。Git 面板的界面文案在各端、各语言下都是英文。

状态是推送的：客户端打开 `GET /api/projects/:id/git/stream`（SSE），先收到当前状态，之后工作区或暂存区每变一次收到一条 `status` 事件。只要有客户端连着，服务端就监听这个项目：macOS 和 Windows 用一个句柄监听整棵目录，其他平台只监听 Git 自己的 index 与 HEAD，并按间隔重读状态来发现文件编辑。变化后等 400 毫秒再读，两次读取的间隔不小于上一次读取耗时的 4 倍（上限 20 秒），所以读一次要几秒的仓库不会被连续的文件写入拖住。被监听期间 `GET .../git/status` 直接返回上一次的结果，`fresh=true` 强制重读。

大仓库下的取舍：未跟踪目录先按目录读取，文件数不超过 2000 时才逐个列出，超出时整个目录显示为一行；历史只标注本地 Branch、Tag 和本地 Branch 跟踪的远端 Branch，All 从本地 Branch 及其上游出发，不遍历所有远端 Branch；远端 Branch 超过 30 个时按名称检出，不逐个列出；一个 Commit 或一次比较涉及超过 300 个文件时不统计行数、不检测重命名，超过 2000 个时只列出前 2000 个；与主线的比较只在切到 Branch 范围时计算。

Checkpoint 是 Riffet 自己的快照，不是 Git 的概念：它把当时所有未 Commit 的文件（工作区和暂存区各一份）复制到状态目录，不产生 Commit，也不写进仓库。每个回合开始时自动保存一个，用来撤销这个回合；也可以手动保存。回合的 Checkpoint 不阻塞消息，和回合同时进行：消息进入发送的时刻之后被改过的文件（看 ctime，被删的看所在目录）、保存期间暂存区条目变了的文件都不纳入，列为未纳入；期间 HEAD 动了就不保存。保存时 Git 不写 index（`GIT_OPTIONAL_LOCKS=0`），不会和 Agent 自己的 Git 命令争锁。Checkpoint 保存工作区与暂存区内容，并列出超出容量限制等未纳入的文件。恢复前需要读取当前变更列表；文件在审阅后变化会返回冲突。恢复会先保存当前状态作为一个新 Checkpoint。

同一目录及重叠目录可以同时运行多个 Agent 会话，不同后端也一样；工作台只阻止同一个会话被重复启动，以及把同一个原生 CLI 会话绑定到两个工作台会话。两个 Agent 同时改一个 checkout 可能互相覆盖，需要隔离的并发任务应使用单独的 Git worktree，然后将该目录添加为项目。删除 worktree 前会检查未提交文件、未推送提交、主工作树及不安全路径。

## 配置与 CLI 管理

设置面板可检查 CLI 版本、模型和 tmux 能力，并访问 CLI 命令注册表。支持状态、关于、模型、团队列表与切换、MCP 列表/工具/启停、插件市场管理和 CLI 更新。需要持续交互的功能可在原生 Cursor 或 Shell 终端完成。

Web 侧栏「自动化」下的「扩展管理」打开独立管理页，也可通过 `/extensions` 或命令面板「打开扩展管理」进入。页面汇总各 Agent/profile 的 Skills、MCP、Plugins、Hooks、Rules、Commands 和配置文件，可切换项目上下文，按 Agent、配置、类型、作用域和来源筛选。列表保留各资源的真实来源，点击后在详情面板查看或编辑。自有文件支持新建、差异预览和保存；插件缓存、受管文件和共享 symlink 保持只读。安装、启停、卸载和认证根据当前 Agent 的实际能力开放；批量启停逐项执行并报告失败。macOS 和移动端保留「设置 → Agent 扩展」入口。

保存使用文件哈希检查和原子写入，旧内容保留备份。敏感配置值显示为 `[REDACTED]`，保存未改动的占位符时保留原值；外部修改产生冲突时先重新读取再合并。无法可靠脱敏与回填的多行凭据需通过原生编辑器修改。JSON 校验语法，TOML/YAML 当前保留原文编辑。配置作用在服务器上；生效方式见保存回执。各 Agent 的覆盖范围与限制见 [扩展管理](../EXTENSIONS.md)。旧项目配置 API 保留兼容。
