# Riffet 收藏

本文是收藏能力的方案契约，与 `docs/WEB.md`、`docs/MACOS.md` 并列：服务端负责存储、同步与重新定位，web 与
Mac App 负责标记、渲染和跳转。

状态：**web、Mac App 与服务端已实现**；手机 App 和用户提问的收藏暂不做。

## 1. 是什么

收藏把 Agent 的一段回复留下来，日后查看、管理并跳回原会话。一条收藏有两种粒度：

- **整条回复**：一轮回复的最终答案。
- **片段高亮**：回复里选中的一段文字，可选黄、绿、蓝、红四色，可附备注。
- **图片与文件**：Agent 过程中展示的图片（服务端保留一份副本），或它读取、修改过的文件（记录路径和改动）。

会话级的「置顶」（`Session.pinnedAt`）已经占用了 Pin 的图标与语义，收藏一律用书签图标，代码实体叫 `Mark`。

参考：飞书 / Slack 区分会话内 Pin 与个人收藏，riffet 只有一个用户，合成一条记录、两处查看；Telegram 收藏保留消息
副本，原消息消失后仍可读；Kindle / Readwise / Hypothesis 按 W3C Web Annotation 的 TextQuoteSelector 定位高亮，
原文变化时重新锚定，找不到的单独标为失联。

## 2. 不变量

1. 收藏不写回任何 CLI 的原生会话，只存在于 `workbench.db`。
2. 每条收藏都带快照（`snapshot.text`），原文找不到或会话被删除时仍可阅读。
3. 原生消息 id 只作为线索，不作为唯一依据；定位失败标 `orphaned`，不删除。
4. 创建按客户端生成的 `id` 幂等；同一条消息只有一条整条收藏，同一段原文只有一条高亮。
5. 生成中的回复不可收藏：Claude 运行中的事件 id（含 `:run:`）不是最终的 transcript id。

## 3. 数据

类型定义见 `packages/contracts/src/index.ts` 的 `Mark` 一节。

| 字段 | 说明 |
| --- | --- |
| `anchor.messageId` / `aliases` | 标记时的 `nativeId` 与 `nativeAliases`；Claude 的 uuid 在 provider 会话 id 变化后仍有效 |
| `anchor.runId` / `nativeTurnId` | 所在回合，原生 id 失效时在回合内按文本找回 |
| `anchor.sequence` | 按事件序号定位的客户端使用 |
| `anchor.generation` | Cursor 的历史代数；变化说明按位置生成的 id 可能已错位 |
| `quote` | 仅高亮：`exact` + 前后各约 32 字的 `prefix` / `suffix`，偏移只作提示 |
| `snapshot` | 整轮答案的纯文本（服务端截断到 32 KiB）、会话标题、消息时间 |

各后端 id 的稳定性决定了为什么需要多条线索：Claude 的 JSONL uuid 稳定；Codex / TRAE 在 item 有 id 时稳定；
Cursor 的 id 由位置组成，回退或分叉后可能错位；Droid 与 DSH 混有序号。

## 4. 定位

`GET /api/marks/:id/locate` 依次尝试：

1. `aliases` 命中任一消息的 `nativeId` 或 `nativeAliases`；
2. `nativeId === anchor.messageId`；
3. 在 `runId` 的回合内按引文或快照开头匹配；
4. 在整个会话中检索引文或快照开头（空白归一化）；
5. 都失败则标 `orphaned`。

找到的 id 或序号与记录不同时回写锚点，下次直接命中。引文来自**渲染后的纯文本**，索引与 transcript 存的是
Markdown 源；服务端比较两者的"骨架"：去掉列表序号、链接地址后只保留字母与数字（含汉字）并转小写。图片只按 id
找回；文件另按路径匹配工具调用；服务端读不到 transcript 时，图片与文件沿用已存锚点交给客户端寻找。

客户端落点：高亮滚到引文本身，整条回复较高时让开头靠上、较矮时居中；折叠的过程块先展开再定位其中的图片或工具
调用。首次定位后约 1.5 秒内逐帧校正（行测量、代码高亮、翻页都会移动内容），用户滚动即停止。

客户端拿到位置后打开会话；目标不在已加载的历史中时逐页向前加载，至多约 30 页，找到后滚动并闪烁高亮；仍找不到则
停留在会话并提示。

## 5. API 与同步

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/marks` | 按会话、项目、后端、类型、状态和关键词筛选，新到旧，游标分页，支持 ETag |
| POST | `/api/marks` | 创建，按 `id` 幂等并去重 |
| PATCH | `/api/marks/:id` | 修改备注、颜色，`null` 清除 |
| DELETE | `/api/marks/:id` | 删除 |
| POST | `/api/marks/delete` | 批量删除 `{ ids }` |
| GET | `/api/marks/:id/locate` | 重新定位 |
| GET | `/api/marks/:id/prompt` | 整条回复对应的提问 `{ text? }`，供导出图片使用 |
| GET | `/api/marks/:id/asset` | 图片副本（`<数据目录>/marks/<id>`，删除收藏时一并删除；创建时 base64 内联，≤ 10 MiB） |

收藏变化沿用列表的变化通知：web 订阅 `/api/lists/stream` 的 `changed`，带 ETag 重新拉取；Mac App 由 KMP 的 `SessionMarks` 随会话列表同一轮询，以 `limit=1` 的 ETag 条件读判断修订是否变化。删除会话时其收藏转为失联。

## 6. 呈现

- **入口**：web 在回复下方菜单「收藏回复」，选中文字后的浮动条「高亮」，图片悬停右上角与读写文件的工具行右侧的书签；
  Mac App 在消息右键菜单「收藏回复」「高亮所选文字」，图片与文件工具调用的右键菜单「收藏图片 / 收藏文件」。
- **会话内**：被收藏的回复显示书签标识；高亮用不改 DOM / 不改存储文本的方式绘制（web 用 CSS Custom Highlight
  API，Mac App 用 temporary attributes）；点击或右键高亮可改颜色、写备注、删除。
- **收藏夹页**：侧边栏顶部与定时任务、扩展管理并列。搜索、按项目 / 类型 / 失联筛选、编辑备注、批量删除；点击跳回原会话。web 深链为 `#s=<sessionId>&m=<markId>`。

### 6.1 导出图片

把一段话或整条回复排成一张卡片，复制或保存为 PNG。web 与 Mac App 各自原生渲染，数值以本节和
`docs/design/mark-share-demo.html` 为准，两端保持一致；服务端只提供提问查询。

- **入口**：收藏夹卡片（整条回复与高亮）、会话里回复的操作菜单「导出为图片」、选中文字后的「导出图片」。
- **尺寸**：竖版逻辑宽 480、外边距 20，按 3× 导出；宽版逻辑宽 720、外边距 28，按 2× 导出，两者都约 1440 px 宽。
  「自动」在回复含 GFM 表格或代码行超过 60 字符时用宽版，片段总用竖版。高度乘倍率超过 16384 px 时降低倍率。
- **卡片**：圆角 16、1px 细边与很淡的双层阴影；内边距竖版 40/36/26，宽版 48/48/26。
- **配色**：纸白（画布 `#EFECE6`、卡片 `#FBFAF7`、正文 `#1C1B19`）、墨黑（画布 `#0E0E0F`、卡片 `#18181A`、正文
  `#ECEAE6`）、跟随主题（沿用当前主题色）。高亮色只用于引号与批注的竖线。
- **片段**：左上悬挂引号（Georgia 68，高亮色）；按字数分三档：≤60 字 26/1.62，≤160 字 21/1.72，更长 18/1.8。
- **整条回复**：正文 16/1.8，标题 600 字重 22/19/16.5；代码块 13 号等宽、自动换行、圆角 10，不显示语言栏与按钮；
  表格只画横线；分隔线为居中的「·  ·  ·」。超过 3000 字在段落处截断，末尾「……」，页脚注明「节选 · 全文约 N 字」。
- **中文排版**：中英间距（`text-autospace`）、标点挤压与行尾悬挂、避头尾、`text-wrap: pretty`。
- **可选内容**：提问（仅整条回复，默认关）、批注（默认关）、来源（会话标题 · Agent · 项目 · 日期，默认开，关闭后页脚只剩字标）。
  主题、字体（黑体 / 宋体）、宽度与来源开关记在本机。
- **提问**：会话里取该回复之前最近的一条用户消息；收藏夹经 `GET /api/marks/:id/prompt` 取搜索索引里早于快照时间的最后一条
  用户消息，会话未被索引时没有。
- **输出**：主操作复制到剪贴板（需安全上下文，否则提示改用保存）；保存为 `Riffet-<会话标题>-<时间>.png`，手机浏览器走系统分享。
## 7. 明确不做

- 手机 App 与用户提问的收藏（后续再做）。
- 多人共享、提醒、写回原生会话。
- 超过四种颜色或颜色语义体系。

## 8. 风险

| 风险 | 应对 |
| --- | --- |
| Cursor 回退后 id 错位 | 代数变化时校验，文本匹配兜底 |
| Codex item 无 id 时不唯一 | 回合 + 文本匹配 |
| 两端纯文本略有差异，同一高亮在另一端偏移不同 | 以引文和前后文为准，偏移只作提示 |
| 分叉出的会话 | 收藏只属于原会话，不随分叉复制 |
| 向前翻页定位过慢 | 页数上限，超出后提示 |
