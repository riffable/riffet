# macOS 设计语言

Mac 客户端的主张、平台行为与动效。字号、字重、颜色、图标和表面的取值按 [Riffet 风格](riffet-style.md)，本文不重复（[决定](DECISIONS.md) 2026-11-25）。改 Mac 界面前先读本文；和本文冲突的旧写法按本文改。

参照了 Apple Music 的克制、Arc 的动效连贯性、macOS 26 的 HIG 与 WWDC25 设计系统，不照搬其中任何一个。调研来源见文末。

## 1. Riffet 的主张

Riffet 是一个看 agent 干活的地方。界面是安静的工作台，agent 和它的产出才是主角。

### 1.1 墨与纸，颜色归 agent

Music 的颜色来自专辑封面，Riffet 的颜色来自 agent。

- 界面本身近乎无彩：墨色文字，低色度的纸面。
- 彩色只来自内容：agent 标志（Claude 橙、Codex 渐变、Cursor 墨）、头像、插件自己的标志、代码高亮、diff。
- 系统强调色只留给系统控件本身：开关打开、文本选区、焦点环、当前选中的列表行。我们自己画的按钮、图标、分段、标签一律不上强调色。
- 状态色只表达状态：红是出错或危险，黄是等你处理。不拿来装饰。
- 一页最多一个实心主按钮，用墨色，不用蓝。
- 代码里用 `palette.mark` 表示「我们自己画的标记」：勾选框、进行中的步骤、选中的卡片、单一序列的图表，取主题强调色；对话正文里的标记（`TranscriptStyle.mark`）是墨色。

### 1.2 注意力跟着正在发生的事

Music 的歌词只有当前一句清晰，其余退后。Riffet 里，正在发生的事才清晰。

- 前景：正在流式输出的回复、等你批准的请求、出错的会话。
- 退后：已经结束的工具调用、历史轮次、元信息（时间、用量），用次要色，或者折叠起来。
- 侧栏只给需要你的状态强标记，比如等待审批、没看过的出错、未读。运行中的会话只在行首转一个小 spinner，结束就消失。
  - 实现：标记在行首的状态槽，与 Web 相同（[模式](system/patterns.md)「侧栏导航」）；等你确认时行尾的时间换成「待确认」；会话行不放 agent 标志。
- 装饰不抢注意力：不加阴影卡片、不加彩色按钮、不加说明性的副标题。

### 1.3 连贯：东西从哪来，回哪去

Arc 好看的地方在于每个变化都有来处和去处，Riffet 也要做到，只是节奏更安静。

- **来处**：菜单和弹出层从触发它的按钮长出来，关闭时收回去。搜索面板从窗口上方落下。
- **原地**：切换页面或会话时，窗口外框、侧栏、工具栏都不动，只有内容交叉淡入，并上移 4pt。不闪白，不重排。
- **变形**：触发按钮直接反映状态，比如发送↔停止、＋↔×、展开箭头旋转。选中态是一个滑到新位置的胶囊，而不是旧的消失、新的出现。
- **流**：流式文字按块淡入，行高事先占住，参见 AGENTS.md 的 Compose 约定里关于首帧和稳定帧的规则，macOS 同理。

## 2. 视觉规则

### 2.1 控件

- 系统有的控件用系统的。自绘控件只在系统没有对应控件时才写，写了全 App 只用这一种。
- 搜索：页面级搜索放在页头（`pageChrome` 的搜索框），不在内容区另画搜索框。
- 筛选：用菜单，图标是 `line.3.horizontal.decrease`。分段控件只用来切换同一份内容的不同视图，选项最多四个。
- 分段控件用 `SegmentedTrack`，不用系统蓝色的 `.segmented`（设置窗口和工具栏里的除外）。选项数量不定的地方（右侧面板的标签）放不下时先收窄，再退成菜单。
- 筛选的当前状态显示在它作用的内容上方，可以逐个移除，不藏在按钮里。比如统计页的时间范围和筛选条件。
- 设置类列表（插件、自动化模板、账户）用系统设置那样的分组框，开关用小号（`.controlSize(.mini)`）。行可点就整行可点，不另加一个配置图标。
- 标签（「开发包」「异常」）只在值得注意时出现，默认状态（内置、已安装、已启用）不显示。

- 窗口失焦：侧栏选中底色退到悬停色，状态胶囊褪成 `fg3`，呼吸标记停住（`appearsActive`）。
- 未读：本机记录每个会话在任一窗口里显示过的最新活动，离开屏幕时再记一次；之后有新活动且不在运行/待确认/出错时，标题加粗、行尾一个 6pt 墨点（`UnreadStore`）。

### 2.2 工具栏

主窗口的页头是绘制的（`CustomHeader`、`CustomPageBar`），单独打开的会话窗口用系统工具栏；两处的入口一致，下面的规则对两者都适用。

- 标题在左。动作在右，最多两三组，每个动作是单独的 `ToolbarItem`，不把一个 `HStack` 塞进一个条目。
- 工具栏里不放说明文字、地址、计数这类状态信息。
- 工具栏里的菜单不带下拉箭头，也不上色。SwiftUI 的 `Menu` 做不到这两点，所以用 `ToolbarMenuButton`。
- 所有工具栏图标同字号、同粗细，不带外圈。
- 只服务某一栏的控件放在那一栏里面，跟着它一起出现和离开。比如侧栏列表的筛选在侧栏头部，不放在工具栏。
- 侧栏收起前后都留在工具栏的按钮（新会话、侧栏开关）不加玻璃胶囊。否则胶囊会在收起动画结束时才出现，按钮跟着跳一下。
- 会话工具栏只有三个入口，和 web 一致：会话信息（目录、分支、面板里的各个视图、终端、子 Agent 与后台任务）、面板开关、⋯（只放对会话本身的操作）。子 Agent 和后台任务不在工具栏放计数，运行中只在会话信息按钮上加一个墨色小点。

### 2.3 层次与表面

- 栏和面板不加自定义的背景、描边或阴影。吸顶内容交给系统的滚动边缘效果，不画半透明底板。
- 卡片只用于本身就是一件独立东西的内容，比如一条收藏、一张审批请求。列表和设置用分组框加分隔线。
- 仪表盘（统计页）每一区都是同一种卡片，不混用卡片和底色块。并排的卡片等高、间距横竖一致；条形列表名称列等宽，默认只显示前 8 行，其余收起。

### 2.4 排版与间距

- 字号与字重按 [Riffet 风格](riffet-style.md) §2。页面级大标题只放在页头标题位置。
- 间距只用 `Space` 里的档位。一页内容只有一条左边缘：分组标题、分组框、页脚说明都对齐它。
- 列表行最多两行文字：名称一行，描述一行。版本、发布者、ID 之类放进详情。

### 2.5 图标

- 图标经 `IconPack` 取所选图标包，默认是 Web 的图标。同一个场景用同一字号、同一粗细。
- 列表行首的图标用这个条目自己的标志：agent 标志、插件声明的图标、首字母方块（底色是从名字取色的低色度色）。不要一类东西全用同一个通用图标。

## 3. 动效

### 3.1 时长与曲线

动画只用三档，写作 `Motion.fast` / `Motion.standard` / `Motion.expressive`（`Theme/Controls.swift`），不再在各处单独写 `easeOut(duration:)`。时长取 Web 的同名档位，由 `pnpm gen:tokens` 从 `packages/contracts/src/design-tokens.ts` 生成。

| 档 | 用途 | SwiftUI |
|---|---|---|
| 快 | 悬停、按下、勾选、图标变形 | `.snappy(duration: 0.15)` |
| 标准 | 交叉淡入、菜单与弹出层、选中胶囊滑动 | `.snappy(duration: 0.2)` |
| 舒展 | 面板、侧栏内容、sheet、搜索面板 | `.smooth(duration: 0.3)` |

### 3.2 只动便宜的属性

正文是 AppKit 自己排版的，长会话重新测量一次就要好几秒；但阅读列宽度不变时转录只移动行（`TranscriptController.widthChanged`），阅读列变窄时在后台重排。所以：

- 位置变化要连续，不用硬切代替过渡；逐帧变化的只能是便宜的部分（转录行的位移、页头、输入框）。
- 切换页面或会话的交叉淡入用 Core Animation 的 `CATransition`，加在内容区自己的图层上；不要在页面容器上挂 SwiftUI 动画，那会每帧重排整个窗口。
- 侧栏、右侧面板、底部终端由使用者开合时，面板滑入滑出，内容区在同一个事务里沿同一条曲线（`Motion.slide`）让出或收回位置（`WorkbenchView.slide`）；滑动期间窗口不接收指针。页面或会话盖住、露出面板时一次到位。右侧面板的占位区要和正文画布一样铺到工具栏下面。

### 3.3 不做

- 大位移和过度回弹。位移不超过 8pt，缩放不小于 0.96。
- 只为好看的循环动画。循环只用于进行中与加载中的指示（运行指示、加载微光、转圈），以及 logo 位置上的氛围品牌标志；每处循环旁注 `motion-loop: <原因>`，`pnpm check:design` 拦截没有标注的循环。
- 遵守系统的「减弱动态效果」设置：所有循环都停下，其余只保留淡入淡出。

## 4. 交付前自审

改完一页，截图和改动前的截图并排对照，逐项过一遍：

1. 这页上有几处强调色？除了系统控件本身，应该是零处。
2. 内容区的左边缘有几条？应该只有一条。
3. 用了几种字号？应该不超过三种。
4. 工具栏里有没有文字、地址，或者一个胶囊里塞了一整排按钮？
5. 窗口失焦时，选中态有没有变淡？
6. 深色模式下看一遍。
7. 每个出现和消失的东西，都有来处和去处吗？
8. 列出新增的用户可见文案，逐条问一遍「删掉它，用户会做错什么？」

- 对话区：最新一条消息的时间、速度和操作常驻；更早的只在指针悬停该行时显示（占位不变）。
