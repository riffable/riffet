Riffet并行尝试 · 重设计 Demo
1 发起2 对比决策3 单个尝试4 历史找回
建议体验：发起 → 等待模拟跑完（含 1 个失败 / 1 个待审批）→ 对比 → 采纳

设计注释

  1. 尝试组是一等对象：发起后进总览而非第一个会话；组在侧栏可展开，关掉会话也能从历史找回。
  2. 决策而非浏览：卡片给摘要 / 测试 / 耗时 / token / 改动量，并算「推荐」及理由（测试通过 + 改动最小），重叠文件在矩阵里高亮——多人改同一文件是最贵的冲突信号。
  3. 全生命周期：停止全部、失败重试（新尝试替代）、追加尝试、丢弃（归档 + 删 worktree）、采纳后一键清理其余。
  4. 采纳前预检：目标分支干净 / 冲突预演 / 文件清单先给结论，冲突不再等点下合并才发现。
