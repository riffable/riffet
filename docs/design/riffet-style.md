# Riffet 风格视觉规则

Riffet 风格（`InterfaceStyle.riffet`）是主风格，以 Web 为准，Mac 与 Web 共用这一页。原生和线条风格保留，各自的规则见 `macos-native.md` 和 `interface-styles/`。这里打磨出来的规则，之后按同样的方式套用到其他风格。

参照对象是 Multica 的桌面端：它用的值很少，每一处都守着这些值。稿件见 `interface-styles/pages/riffet-next/`，用 `./render.sh riffet-next` 渲染。

## 1. 谁决定什么

| 层 | 决定 | 不决定 |
|---|---|---|
| 风格（本文） | 用哪种组件、尺寸档位、某个位置用哪个颜色角色 | 具体色值 |
| 主题（`docs/THEMES.md`） | 每个颜色角色的取值 | 某个位置用哪个角色 |
| 用户设置 | 字体、字号缩放、材质与透明度 | 组件结构与档位 |

规则只引用角色（`fg`、`line`、`bg-active`……）和档位，不写色值，因此换主题、换字体、调缩放后规则依然成立。

## 2. 文字

| 档 | 字号 / 行高 | 用于 |
|---|---|---|
| 阅读 | 14 / 23 | 对话正文、用户消息、输入框 |
| 界面 | 13 / 20 | 行、标签、按钮、菜单、工具名 |
| 次要 | 12 / 16 | 时间、计数、分组标题、元信息、路径 |

- 只用 400 和 500 两种字重。500 用于分组标题、工具名、未读会话；600 只留给品牌名。
- 文字色分三级：`fg` 用于内容和当前项，`fg-2` 用于其余行，`fg-3` 用于元信息。`fg-4` 只用于占位、快捷键和行尾时间。
- 等宽字只用于代码、命令和路径。工具调用的说明文字是自然语言，用界面字体。
- 行内代码不加底色，用等宽字体，字号取 0.86em，颜色比正文弱一档（`fg-2`）。

## 3. 线、面、圆角

- 只用一种分隔线：1px `line`。列头、标签栏底边、卡片外框、代码块都用这一种。
- 层次靠底色：窗口底是 `bg-sidebar`，内容卡片是 `bg`，选中是 `bg-active`，悬停是 `bg-hover`。卡片不加阴影。
- 只有浮在内容上的东西才有阴影：输入框、菜单、弹出层，用 `shadow-float`。
- 圆角取 Web 的四档：控件和行 8（按钮、页签、胶囊、列表行），容器 10（代码块、菜单），卡片 12（窗口内容卡、用户消息），浮层 16（输入框、弹出层）。嵌套时内圆角 = 外圆角 − 内边距。

## 4. 颜色

- 强调色只用于焦点环、文本选区和链接，不用于按钮、图标、分段控件或运行状态。
- 主按钮（发送、提交）用 `primary` 实心，每个区域最多一个。
- 状态色只表示状态：待确认用 `warning` 描边小标签，出错用 `danger`，diff 增删用 `success` / `danger`。
- agent 标志保留品牌色：它是内容（哪个 agent 在干活），不是界面装饰。
- 以上是阅读面的规则。看板、统计、工作台类页面是概览面，可以用降饱和的数据色和一处渐变，上限见[基础](system/foundations.md) §12。

## 5. 尺寸与间距

- 间距取 4 的倍数：4 / 8 / 12 / 16 / 24 / 28。同组元素间距 4–8，组与组之间 16，对话轮次之间 24–28。
- 行高 30（侧栏、面板列表），标签和图标按钮 28，胶囊 26，卡片头 44。
- 图标用 Lucide，1.25px 描边。Web：主导航 18，按钮和页签 16，行内 14，元信息 12。Mac 的图标按字号排，同样的数字画出来比 Web 大，不照搬：主导航 12.5，按钮和页签 13（与标签栏的按钮相同），元信息 11。左栏、标签栏、右侧面板的同类图标一样大。
- 同一排图标按钮间距一致，不分组隔开。主导航图标颜色跟随所在行的文字，其余降一级。文件夹和文件一样用 `fg-3` 描边图标。
- 对话列宽 680，输入框比列宽多 24，两边各伸出 12。

## 6. 组件

窗口里的控件只有两种：**图标按钮**（28 × 28，透明底，选中时 `bg-active`）和**胶囊**（高 26，文字加可选的下拉箭头，透明底）。模式、模型、Git 范围这类选择都用胶囊，不用纯文字，也不用分段控件。

- **输入框**：和 Web 一致，左下只有一个「+」，菜单里依次是「添加图片或文件」「引用会话」，分隔线下是「技能与工具」（行尾显示已选数量）。「+」右边是模式胶囊，右下是模型胶囊和发送键。

- **标签栏**：当前标签保留完整标题，最宽 280；其余标签宽 96–160，先缩窄，放不下时收进「+N」菜单。agent 标志保留品牌色，运行中的标签用 spinner 代替。关闭按钮只在当前标签上显示。
- **侧栏行**：一行只有标题和行尾，行尾依次放待确认标签、未读点、spinner 或相对时间。
- **右侧面板**：每个区域只有一行页签。面板视图用图标页签，当前视图带文字；视图内部的子页（Changes / History …）是第二行，也是最后一行。范围、筛选放进列表头的胶囊。
- **运行状态**：一个回合只在末尾显示一处运行状态（「正在处理」、耗时、速度）。运行中，回合开头的折叠标题只写「Working」，不计时、不闪烁；结束后写结果，比如「Processed · 1m 41s」。
- **弹窗**：菜单、弹出层、`/` 和 `@` 菜单、模型选择器共用一种浮层：`bgPopover` 底、1px `line`、圆角 12（`radii.menu`，Web 的 `rounded-xl`），阴影取 Web 的 `shadow-pop`（贴边的浅影叠一层柔和投影）。内边距 4，行高 32，行圆角按嵌套规则取 8。分组标题 12/500 `fg3`，与行内文字对齐。弹窗里的选择用不带边框的胶囊（值加下拉箭头），开关用墨色；不用系统的 ⇕ 弹出框，也不用蓝色开关。
- **输入框的胶囊**不带下拉箭头，和 Web 一致；箭头只出现在弹窗里的选择上。
- **工具行**：图标、工具名（500）、目标（等宽、`fg-3`），行尾放结果量。命令用带框的终端图标（`square-terminal`），不用裸的 `>_`：裸的上下左右都不平衡，读起来像文字。

## 7. 落到代码

规则通过风格配方生效（`packages/contracts/src/interface-styles.ts`，`pnpm gen:styles` 生成 Mac 的 `StyleSpec`），代码判断配方字段，不判断风格名：

| 配方 | Riffet | 作用 |
|---|---|---|
| `text` | 13 / 12 / 12 / 13，正文行高 23 | 界面三档字号；对话正文行高 |
| `inlineCode: plain` | | 行内代码无底色，12pt 等宽，次一档墨色 |
| `ink: quiet` | | 运行状态不用强调色，只在回合末尾计时；开关用墨色，弹窗里的选择是胶囊 |
| `toolRun: labelled` | | 工具名、说明用界面字体，只有命令用等宽 |
| `tabs: pill` | | 面板视图用图标页签，Git 子页是胶囊，范围收进胶囊菜单 |
| `fileRow: inline` | | 文件名和目录在同一行 |
| `radii.menu` | 12 | 菜单和弹出层的圆角（输入框仍是 16） |

其他风格想采用某条规则，改自己的配方即可。

## 8. 交付前自审

改完一页，截窗口，和稿件并排比较：

1. 文字有没有超出三档字号、两种字重？
2. 分隔线是否只有一种？卡片上有没有阴影？
3. 强调色出现在几处？除焦点环、选区和链接外应该是零处。概览面另按[基础](system/foundations.md) §12.6 查一遍。
4. 左栏、标签栏、右侧面板的图标并排看是否一样大？有没有标题被截到只剩几个字？同一个区域有没有两行以上的页签？
5. 同一种东西是否用了两种控件，比如一处是胶囊、另一处是纯文字？
6. 一个回合里有几处运行状态？应该只有一处。
7. 深色主题下再看一遍，再换一套浅色主题看一遍。
