# 移动端页面

手机只有一列、一只手、一个拇指。组件做对了，页面仍然可能难用：信息放错了层级，一屏里塞了三件事，低频的工具压在内容上面。本文规定 Android 与 iPhone 的二级页面、浮层和面板怎么组织，是[模式](patterns.md)在手机上的版本；单个组件的写法见 [Android](android.md) 和 iPhone 的 `Design/`。

范例是 iPhone 的「Agent 扩展」页（`apps/mobile/iosApp/Riffet/Features/Management/NativeExtensionsView.swift`，2026-11 随设置页一起重做）。反例是 Android 的同一页（`ui/settings/ExtensionsSection.kt`），§6 逐项对照。

## 1. 原则

1. **一页一件事。** 目录页只列对象；一个对象有自己的详情页；编辑和新建是单独的任务。一页里不靠状态在列表、详情、编辑器之间切换。
2. **第一屏给来意。** 用户进来要找的东西在第一屏：对象列表、当前值、主操作。选择范围的控件压成一行胶囊，低频的工具收进顶栏菜单或页尾。
3. **往下钻，不原地变形。** 点一行就压栈打开它，返回手势回到原处、滚动位置不变。不要「返回列表」按钮。
4. **只在例外时说话。** 行的副标题写区分它的信息；状态只在偏离常态时出现（「已停用」「异常」），常态不写。
5. **拇指够得到。** 主操作在顶栏右侧或页面底部的一个按钮；对单个对象的操作在详情页或长按菜单里；点击区至少 48dp（iOS 44pt）。
6. **出错的地方就地说。** 加载失败在内容的位置给出原因和重试；操作结果用 Snackbar 一句话；原始输出只在失败时出现，并且折叠。

### 1.1 小屏的视觉

规则跟着 Material 3 的手机规格走（导航抽屉、侧边面板、列表、页签），iPhone 对应系统列表。

- **一个面一套字阶。** 整页：顶栏标题 22，行 16，次要 14。底部面板、侧边面板和侧栏也用这一套：面板是同一个应用的一部分，头部用顶栏标题（`barTitle`），分组、行、值用整页的分组卡片与行（`Group`、`GroupTitle`、`GroupRow`），跟着界面风格变。不给面板另做一套更小的字阶：单看合乎 Material 导航抽屉，放在整页旁边就显得又小又细。
- **对象列表的行只一行。** 文件、会话、任务、模型这类对象列表，行的标题、副标题各一行，放不下就截断（路径截断开头，保留文件名），不折成两行；设置项的标题可以折行。同一张卡片里行高相同，不混排大行和紧凑行。
- **切换视图用页签，选一个值用分段。** 一页里几个视图（Git 的变更、历史、检查点、工作树）用可滚动的页签（`ViewTabs`），标签永远完整。分段控件只用于二到三个短选项的值（浅色、深色、跟随系统）；Material 3 已在弃用分段按钮，长标签放进去必然截断。
- **状态用颜色和字，不用徽章。** 文件状态是固定宽度里的彩色字母（M、A、D），任务状态是小圆点，不画 32dp 的圆形底板。头像只给人和 Agent。
- **胶囊只有一个尺寸，三种用途。** 一组里选一个（筛选条）是 `ChipRow`；打开菜单或选择面板的是 `ChipButton`，尾部一个下箭头，显示当前值；一个开关（Fast、Max）是 `ToggleChip`，选中时底色变成选中色。三者同高、同圆角、同字号，可以混排在一行里；不在业务代码里另画胶囊。
- **选中只用一种标记。** 在一列里选一个值（选择面板、菜单、问答的单选）：当前值行尾一个强调色的勾，行本身不填充；按下和键盘焦点的底色只是暂时反馈，松手就消失。多选用勾选框。「你现在在哪」（底栏、侧边导航、页签、平板上的当前会话）用填充或指示条，不加勾。胶囊和分段控件：选中只填充，不加勾。
- **主次靠填充分出来。** 一屏的主对象（新会话页的输入框、编辑页的表单）用实底卡片，与设置页的分组卡片同色；同一屏的次要入口用描边、不填充（Material 的 filled 与 outlined），不能比主对象更实。磨砂和玻璃只给浮在内容上的东西（会话页的输入框、底栏、浮层）；新会话页的输入框后面没有滚动的内容，用实底。
- **占位符、提示用三级墨色（`fg3`）。** 与输入的文字同字号，不用主色；手机上的磨砂和玻璃底上 `fg4` 读不清，占位一律 `fg3`。
- **行尾只放一样。** 数字（`+2 −1`）用 12 号等宽数字；开关、勾选框、箭头、值四者选一。
- **同一个面板一种节奏。** 入口和小操作用同一种操作条（图标在上、一个词在下）；卡片的圆角、分隔线与整页的分组卡片相同。
- **长文案先验。** 交付前用长标题、长文件名、长服务器名和二十个以上的条目各看一遍，再看一遍英文。

## 2. 页面类型

每个二级页面属于下面一种。说不清属于哪种，通常是把两种页面做进了一页，先拆开。

### 2.1 目录页

列出一类对象，供用户找到其中一个。

| 从上到下 | 写法 |
|---|---|
| 顶栏 | 标题；右侧是搜索、添加（`+`，多种添加方式时是菜单）、⋯（低频工具：刷新、诊断、导入导出） |
| 范围条 | 决定列表内容的上下文（Agent、项目、服务器），每个是一枚菜单胶囊，显示当前值；一行放下，不做成表单分组 |
| 筛选条 | 类别胶囊，带数量，第一个是「全部」；只有一类时不显示 |
| 列表 | 按类别分组；「全部」下每组只显示前 5 个，组尾一行「全部 N 个」切到该类别；行见 §3 |
| 页尾 | 次要信息折成一行（「诊断 3」），点开是自己的页面 |

- 刷新用下拉，不放「刷新列表」按钮。长列表用懒加载，不放「再显示 40 个」。
- 整页加载是居中的转圈，不配文字；加载完是空的，给空状态和下一步（「没有扩展」+ 添加）；搜索无结果另有一种空状态。

### 2.2 详情页

一个对象的全部信息和操作。

| 从上到下 | 写法 |
|---|---|
| 头部 | 图标、名称、类型 · 范围，一段说明；不放进卡片，直接在页面上。人（个人资料）的头部是 96dp 头像、下面整页标题字号的名字和一行范围（「所有连接这台服务器的设备共用」）；头像右下角一个编辑标记，点头像弹出菜单（从相册选择、随机、移除） |
| 主状态 | 对象最常改的一项，通常是「启用」开关；只读的状态（「已加载」）作为值行 |
| 关联 | 来源文件、所属插件、配置文件，每行打开一个对象 |
| 操作 | 其他操作是一行一个的文字操作（强调色），点了先确认 |
| 危险操作 | 卸载、删除单独成组放在最底部，`danger` 色，确认的标题写明动作和对象 |

- 只读的原因、生效方式、路径写在对应分组下面的一行说明里，路径可以选中复制。
- 操作进行中，顶栏右侧转圈，页面禁用；完成后用 Snackbar 报告，详情就地刷新。

### 2.3 编辑页与新建页

一次提交的任务：改一份配置、新建一个对象、填一组参数。

- 全屏页面（Android 压栈，iPhone 是带导航栏的 sheet），顶栏左侧取消，右侧保存（或「创建」「安装」）；没有改动时保存不可用。
- 字段少，带标签，给默认值；不常用的放进「高级」折叠组。
- 字段是分组卡片里的一行（`GroupField`）：卡片就是输入框的容器，字段不再画边框和底色，字号与行一致，分隔线由卡片画。一组里有几个字段时，标签在字段内、文字上方，次要字号三级墨色；只有一个字段时不写标签，页面标题就是它的名字。不在卡片里放描边输入框，也不在卡片里另起一行标签再放输入框。
- 改一个值（名称、备注）也是一页编辑页，顶栏右侧保存，键盘的完成键同样保存；不靠失焦自动保存，用户看不出改动有没有生效。
- 代码和长文本独占一页，编辑区占满剩余高度，路径和说明在编辑区上下各一行。不做「保存前预览」的两步：服务器拒绝时把原因显示在编辑区下方，内容保留。
- 有未保存的改动时，取消、系统返回、右滑返回都先确认「放弃未保存的修改？」，答案只有放弃和继续编辑：保存是顶栏的按钮，不在确认里再给一次。

### 2.4 设置分类页

一组相关的偏好。行只有四种：

| 行 | 右侧 | 点了 |
|---|---|---|
| 导航行 | 当前值 + 箭头 | 压栈打开下一级 |
| 开关行 | 开关 | 整行切换 |
| 选择行 | 当前值 | 打开选择面板（§2.5）或菜单 |
| 操作行 | 无，标题是强调色的动词 | 执行或先确认 |

- 行里不放按钮，更不放和行标题同名的按钮（「安装插件 [安装]」）。需要一个按钮，就把整行变成操作行。
- 说明只写用户推断不出的（存储位置、是否需重启、计费），放在组下面一行。

### 2.5 选择面板

从一组值里选一个：底部面板，标题 + 可选的搜索，一列选项，当前值在行尾打勾，选了就关。标题与行的文字左对齐，有返回时在返回之后；副标题与标题对齐。选项少（2–4 个）且就在触发处时用菜单；选项需要预览（主题、界面风格）时用缩略图卡片。

### 2.6 弹窗

只用于确认，或者要一两个字段（重命名）。

- 标题写动作和对象：「卸载「frontend-design」？」；正文只写推断不出的后果（不可恢复、连带删除什么）；确认按钮就是那个动词，危险时 `danger` 色。
- 不写「此操作将执行所选动作」这类通用说明；标题不重复按钮。
- 超过两个字段、需要滚动、有分组的内容，改用编辑页。

### 2.7 面板与侧栏

会话详情、工作台侧栏这类从屏幕边缘拉出的面板。面板一次会话里要打开很多次，第一屏就要能一下点到常用的东西，事实一眼扫完。部件是整页分组卡片的薄封装，字号、行高、圆角与整页一致，面板自己的只有头部、操作条和状态圆点。

| 从上到下 | 写法（Android `ui/app/PaneParts.kt`） |
|---|---|
| 头部 | `PaneHeader`：与顶栏同高，标题用顶栏标题的字号一行，下面一行次要字号的状态；右侧关闭，进入下一级时左侧是返回 |
| 常用入口 | `PaneActionBar`：一张卡片上二到四格，图标在上、一个词在下，各开一样东西 |
| 正在进行 | `PaneSection` + `PaneRow`：只在有内容时出现，标题右侧写数量（「2 个运行中 · 共 26」）；先列运行中的前三项，进行中的行尾是停止（要确认），其余用「全部 N 个」进入下一级 |
| 事实 | `PaneValueRow`：标签在左、值在右，一行；路径、分支用等宽并截断开头 |
| 低频操作 | 第二个 `PaneActionBar`：置顶、重命名、归档…，最多四个 |
| 危险操作 | 删除单独一张卡片放在最下面，`danger` 色，确认 |

- 头部固定，正文独立滚动；行高统一，同一块里不混用卡片行和紧凑行。
- 不在面板里放表单和日志；需要填写或细看的内容压栈成页面，或在面板里进入下一级。

## 3. 行## 3. 行

- **名称**一行，截断在末尾；**副标题**一行，写区分它的信息（范围、来源、描述的第一句），不重复所在分组的名字。
- **右侧**只放一样：当前值、状态（仅例外时）、开关、箭头之一。
- 图标统一放在左侧的图标位里，同一组要么都有要么都没有。
- 行高按 [Android](android.md) §2.2 / iPhone 的系统列表；连续的行之间不加按钮、不加说明段落。

## 4. 顶栏

- 左：返回（根页是菜单）。中/左：标题（风格决定位置）。右：最多两个图标操作，再多收进 ⋯。
- 搜索：iPhone 用系统的 `.searchable`；Android 是顶栏里的搜索图标，点开后顶栏变成搜索框，返回收起。
- 页面里的工具一律考虑能不能进顶栏；进不了顶栏的，放在内容末尾的一行，不放在内容上方。

## 5. 反馈

| 情形 | 写法 |
|---|---|
| 整页加载 | 居中转圈，无文字 |
| 局部加载（一行、一个值） | 该处的小转圈或骨架，周围不动 |
| 加载失败 | 在内容的位置：一句原因 + 「重试」 |
| 操作成功 | Snackbar 一句话；需要用户做下一步时附操作（「重启服务器」） |
| 操作失败 | Snackbar 或就地一行说明；服务器输出折叠在「详情」里 |
| 空 | 图标 + 一句话 + 下一步操作；搜索无结果另写 |
| 搜索无结果 | 一句「没有找到「关键词」」，不给操作，不放图标 |

共用三个组件（Android `ui/design/Feedback.kt`），业务代码不另画：

- **`Notice`**：页面或对象的一件事，就地放在卡片上：种类图标（信息、成功、警告、错误，图标着色，文字仍是墨色）、可选的标题、一句话、最多一个操作。**一件事只在一处说**：卡片、行、顶栏已经在说的，提示条不再重复（等待你回答的问题在问答卡片上，顶部不再挂一条）；一页同时最多一条，按严重程度取最高的。
- **`EmptyState`**：没有内容时在内容的位置：可选图标（三级墨色）、可选标题、一句话、下一步的按钮。占满剩余高度时上下居中；在列表里时上下留白、不居中。
- **`SkeletonBlock` / `SkeletonRows`**：局部加载时画出将要出现的形状，尺寸与真实内容一致，缓慢明暗变化，减弱动效时静止。整页加载仍是居中转圈。

## 6. 范例：Agent 扩展

| | Android 原来（2026-11-15 前的 `ExtensionsSection.kt`） | 按本文（iPhone 与现在的 Android） |
|---|---|---|
| 第一屏 | 「CLI」「配置」两个表单行、搜索框、「类型」下拉行，然后才是列表 | 两枚范围胶囊、类别胶囊，然后是列表 |
| 找一项 | 搜索框是页面里的输入框；类型是下拉菜单 | 顶栏搜索；类别胶囊带数量，每类先显示 5 个 |
| 看一项 | 同一页切到详情，顶部一个「返回扩展列表」按钮 | 压栈打开详情页，系统返回回到列表 |
| 改状态 | 「扩展管理」组里每个动作一行，行尾是同名按钮（「启用 [启用]」） | 「启用」开关；其他动作是文字行；卸载单独在最下面 |
| 改文件 | 详情下方内嵌编辑器，「预览保存」→ 前后对照 →「确认保存」 | 打开文件进入编辑页，顶栏完成 / 保存 |
| 新建、安装 | 分组标题旁的「新建」菜单；「管理」组里展开一段安装表单 | 顶栏 `+` 菜单，各自打开新建页、安装页 |
| 低频工具 | 「刷新列表」「加载说明」「运行状态 [检查]」「MCP 配置 [重载]」按钮堆在页尾，结果追加在下面 | 下拉刷新；运行状态和诊断各是一行，点开是自己的页面 |
| 结果 | `notice` 把服务器输出、认证地址原样贴在页顶 | Snackbar；输出只在失败时显示在详情页 |

原来的问题大多来自一处：Android 设置子页用的 `SettingsPage` 没有顶栏操作参数，搜索、添加、刷新只能写进内容里。补上之后（§8 第 1 步），页面才能照右栏重做。

### 7.3 场景

2026-11-15 对照 Web 盘点后，手机特有的场景写进了 §9。下面是代码与 §9 还不一致的地方。

| 场景 | 不一致 | 工作量 |
|---|---|---|
| 会话页 §9.1 | 停靠卡片的顺序是目标、待办、队列，问答卡片在另一个容器里，没有「最多两张」的限制（`composer/Composer.kt`、`session/SessionScreen.kt`） | 中 |
| 文件预览 §9.3 | 没有 ⋯ 菜单（复制路径、分享）；在项目外与被截断两条提示可能同时出现（`files/FilesPanel.kt`） | 中 |
| 下载 §9.4 | 失败的行没有行尾「重试」，只能点整行或在菜单里重试；非分组风格的行仍是 Material `ListItem`（`downloads/DownloadsScreen.kt`） | 小 |

## 9. 场景

§2 的页面类型之外，手机上几处有自己结构的界面。规则与 Web 一致的不重复，见 [界面](surfaces.md)。

### 9.1 会话页

| 从上到下 | 写法 |
|---|---|
| 顶栏 | 返回、标题一行、右侧打开会话详情面板（§2.7）；手机与服务器的连接写在标题旁：健康时不写，同步中、离线多久、断开（带「重试」） |
| 提示 | 只放会话层面的一件事（`Notice`，§5），几件同时发生时取最严重的一件：Agent 自己的连接失败、历史同步失败、Agent 的通知、需要在终端里回答。等待你回答、批准的问题不在这里，在输入框上方的卡片上。这类提示消失时短暂写一句「已恢复」 |
| 转录 | 阅读列：正文 16，工具行一行、标题截断、行尾的数字（`+3 −1`、文件数）不换行；代码块、表格在块内横向滚动，不撑宽页面 |
| 输入框上方 | 停靠卡片自下而上：问答与批准、目标、待办、斜杠和 @ 菜单；同一时刻最多两张，问答优先；每张有自己的关闭或收起 |
| 输入框 | 浮在转录上的玻璃岛（[界面](surfaces.md) §2）；发送中、运行中按钮换成停止 |

- 键盘弹出时，转录贴底跟随，停靠卡片随输入框上移，顶栏不动。
- 离线时转录显示最后一次同步的内容，输入框保留草稿但不能发送；手机重新连上服务器后自动同步，不另弹提示。

### 9.2 终端

全屏页面（压栈），顶栏是会话名、连接状态、「接管」和 ⋯；下面是终端，底部两行工具键（常用键 Esc、Tab、Ctrl、方向键、⏎，和组合键），工具键与输入法同时出现。横屏时终端占满，工具键仍在底部。会话由终端接管期间，会话页的输入框位置换成一条保持条：「在终端中」和「收回」（把会话收回到手机上继续）。

### 9.3 文件预览

详情页（§2.2）的变体：顶栏标题是文件名，下面一行是所在目录；顶栏右侧下载和 ⋯（复制路径、分享）；「预览 / 源码」分段在顶栏下（只有能预览的类型才出现）。顶栏下的提示条（在项目外、内容被截断）同时最多一条。代码用等宽小号、行号、横向滚动；HTML 预览在页面内渲染，不跳到浏览器。

### 9.4 下载

目录页（§2.1）：一行一个文件，进行中的行显示进度条和剩余大小，失败的行副标题写原因、行尾是「重试」；完成的行点开即打开文件。空状态写「下载的文件会出现在这里」以外的事实：保存位置。

### 9.5 子 Agent

与会话页同一结构，顶栏标题是子 Agent 的名称，标题下是状态（运行中、已完成、失败）；只读，没有输入框；运行中时顶栏右侧是「停止」（先确认）。

### 9.6 导入终端会话

选择面板（§2.5）：先选范围（这个项目、某个目录、全部），Agent 是一枚筛选胶囊；列表一行是会话标题，副标题是目录 · 分支 · 最近活动；选中即导入。

### 9.7 首次连接与配对

一页一件事，往下钻：

1. 连接页：标志、一句说明（Riffet 运行在你的服务器上），主按钮「配对」；配对过的服务器列在下面。
2. 配对页：编辑页（§2.3），两个字段（服务器地址、配对码），顶栏右侧「配对」，扫码是顶栏的图标，粘贴是配对码字段里的图标。
3. 扫码：压栈的整页相机和取景框，扫到即回到配对页并填好两个字段。
4. 失败：在配对页用 `Notice` 写原因和下一步（码已过期：在电脑上重新生成；网络不通：检查地址），字段保留，不回到第一步。

已配对的服务器在设置里是目录页，当前连接的一行标「当前」；切换在左侧栏的服务器行里。

### 9.8 离线与重连

- 列表页：顶部一条 `Notice`（未连接，带「重试」），是这一页唯一的提示；下拉刷新在离线时立即结束。
- 会话页：见 §9.1。
- 写操作（发送、改名、删除）在离线时不可用，不排队；草稿保留。

### 9.9 系统权限、通知与快速对话窗口

权限在用到时才请求（相机在扫码时，通知在第一次开启通知时），请求前不另弹说明。被拒绝后，用到它的地方显示一行 `Notice`，操作是「去系统设置」。快速对话窗口是独立的系统窗口，按底部面板（§2.5 的外壳）写，字阶同整页。

### 9.10 宽屏与横屏

- 宽度 ≥ 600dp：底栏换成侧边导航栏。≥ 840dp：列表与详情双栏（会话列表 + 会话页，设置分类 + 分类页）。单栏时正文最宽 840dp 居中。
- 横屏手机按手机的竖屏规则，只是高度小：大标题直接收进顶栏，底部面板最高占屏幕 90%。

### 9.11 长按、排序

- 对象列表的行（会话、文件、收藏、历史头像）长按出菜单，菜单里是这一行的全部操作，危险操作在最后、`danger` 色；有长按菜单的行，详情页里有同样的操作，长按只是捷径。
- 排序用「编辑」模式：顶栏「编辑」进入，行尾出现拖动手柄，完成后退出；不用菜单里的「上移 / 下移」。
