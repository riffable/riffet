# 文案

界面文字的写法：语气、用词、错误、空状态、确认、术语、时间与数字。排版（空格、标点、截断、换行）见 [基础](foundations.md) §2.4，不在这里重复。设计规范页的「文案」一章画出对照。

核心规则：**界面文字只写用户推断不出的信息。** 界面已经说明的不再复述；一条不超过一句。

## 1. 语气与人称

- 陈述事实，不评价，不写营销腔和情绪词（「太棒了」「轻松」「强大」）。
- 不用感叹号。
- 不称呼用户为「您」；多数句子没有主语：「已保存」「发送失败」。需要主语时说「你」，说明软件的行为时用「Riffet」或功能名，不用「我们」。
- 状态用结果表达：「已保存」，不写「保存成功」；「发送失败」，不写「抱歉，发送失败了」。
- 一个界面里同一件事只说一次：时间线里已展示的失败不在消息下重复（[DECISIONS](../DECISIONS.md) 2026-11-12）。

## 2. 什么时候写说明

只保留用户推断不出的信息：

| 写 | 例 |
|---|---|
| 存储位置 | 「仅保存在这台 Mac」「仅保存到服务器，不会回显」 |
| 能否撤销 | 「删除后无法恢复」 |
| 是否跨设备、影响范围 | 「安装和启停影响连接这台服务器的所有客户端」 |
| 是否需要重启 | 「新配置将在后端重启后生效」 |
| 权限、隐私、计费 | 「Codex 本周额度剩余 8%」 |
| 空状态的下一步、不可逆确认的后果 | 见 §4、§5 |

不写：

- 复述控件名称或显然的行为（分组标题下再列一遍控件；开关下写「开启后启用」）。
- 「点击」「选择」「支持」式操作说明。
- 解释设计取舍。

设置页的分组说明是一行 `note`（`SettingsGroup` 的 `note`），位于卡片下方；只在行本身说不清存储、费用、风险时才有。

交付前自检：列出新增的用户可见字符串，逐条问「删掉它，用户会做错什么？」答不上来就删。

## 3. 按钮与菜单

- **动词开头**，写出会发生的事，与结果一致：「删除会话」，不写「确定」；「新建会话」，不写「提交」。
- 确认按钮与弹窗标题对应：标题「删除这个会话？」，按钮「删除会话」，取消按钮「取消」。不用「是 / 否」「确定 / 取消」。
- 同一个动作在各处同名：「收藏」「取消收藏」成对；「关闭」用于关闭窗口和标签，「移除」用于从列表拿掉但不销毁，「删除」用于销毁。
- 按钮进行中用 spinner 替换文字，宽度不变（[基础](foundations.md) §9）；需要说明进行中的内容时写「正在读取…」，现有文案有约 40 条「正在…」，保持。
- 菜单项和按钮不加句号。需要省略号表示后续还要输入时用 `…`（「删除…」「从终端导入…」）。
- 只有图标的按钮用 `Tip` 写名称，名称同时是 `aria-label`（[基础](foundations.md) §10.1）。

## 4. 错误信息

两件事：**发生了什么**，以及**下一步能做什么**。

| 差 | 好 |
|---|---|
| 「操作失败」 | 「发送失败，可恢复内容后重试」 |
| 「出错了」 | 「会话暂时无法读取，请重试」 |
| 原始错误码 | 一句人话；错误码、堆栈放进可展开的详情（`FailureDetails`） |

- 先说对象和结果（「无法读取 package.json」），再说原因或建议。
- 能自动恢复或已经恢复的不报错。
- 提示形式的选择见 [模式](patterns.md)：瞬时结果用 `toast`，常驻状态用 `Notice`，输入框旁用 `FeedbackNotice`，表单字段旁用字段下的 `text-danger` 行。
- 错误原因文字可以选中复制（[基础](foundations.md) §2.4）。

## 5. 空状态与确认

**空状态**（`EmptyState`）：标题说明为什么空（「还没有收藏」），不写「暂无数据」；若用户能做点什么，用一句话给出下一步（「在会话里收藏回答或片段，会出现在这里」）；有主操作时放一个按钮，没有就不放。

**确认弹窗**（`confirmDialog`）：

- 标题是问句，写出对象：「删除这个会话？」，不写「确定要删除吗？」。
- 一句说明只写后果：「删除后无法恢复」。可逆的操作不弹确认，给撤销（`toast` 的 `action`）。
- 按钮是动作：「删除会话」；取消写「取消」。
- 危险按钮不作默认按钮，`destructive: true` 时初始焦点在「取消」（[DECISIONS](../DECISIONS.md) 2026-11-14 · Mac 的行为跟平台）。

## 6. 术语

同一个东西只有一个名字。中文界面用中文名，开发者熟悉的英文标识保留原文（[DECISIONS](../DECISIONS.md) 2026-10-27）。取自 `apps/web/src/locales/zh-Hans/*.po` 与界面。

| 用语 | 说明 |
|---|---|
| Agent | 保留英文，指 Claude、Codex 等执行任务的程序；不译为「智能体」 |
| 会话 | 与 Agent 的一次对话；侧栏、标签、信息面板都叫会话，不叫「对话」「聊天」 |
| 项目 | 会话所在的目录；「保存为项目」「还没有项目」 |
| 技能与工具 | 输入框里选择 Skill、MCP、手机控制、浏览器的入口（[DECISIONS](../DECISIONS.md) 2026-11-10）；入口内的条目写 Skill、MCP，保留英文 |
| 插件 | 扩展 Riffet 自身的包；「启用插件」「卸载插件」。Agent 自带的扩展叫「Agent 扩展」 |
| 收藏 / 收藏夹 | 动作和集合；取消写「取消收藏」 |
| 任务 / 定时任务 | 任务是一等实体；按计划运行的叫定时任务 |
| 产出 | 会话改动的文件汇总，含 shell 命令改动的文件 |
| 审批 | Agent 请求权限时的确认 |
| 终端 | 「终端」「Shell 终端」；「从终端导入…」指导入命令行里的会话 |
| 标签 | 标签栏里的一页；「关闭标签」「加入标签栏」 |
| 置顶 / 归档 | 会话的整理动作，取消写「取消置顶」 |
| Riffet 浏览器 | Agent 的浏览器插件，与 Agent 自带的浏览器工具区分（[DECISIONS](../DECISIONS.md) 2026-11-13） |

保留英文、不翻译的：

- **模型名**：原样书写（`gpt-5`、`claude-sonnet`），不加中文。
- **工具名**：`Read`、`Bash`、`Edit` 等，原样、用界面字体的 500 字重（[DECISIONS](../DECISIONS.md) 2026-10-27）。
- **Git 面板**：面板内所有可见文案都用英文，中文界面下也一样，复数写对（1 file / 2 files）；面板以外照常本地化（[DECISIONS](../DECISIONS.md) 2026-11-12）。日期与相对时间也是英文（`apps/web/src/app/panels/gitFormat.ts`）。
- 品牌与产品名：Riffet、Codex、Claude、Cursor。
- 已下线的概念不再出现在文案里：空间（0.6.0 删除）。

## 7. 时间与数字

格式化由函数统一给出，文案里不手写格式。

| 内容 | 写法 | 函数 |
|---|---|---|
| 时长 | `42s`、`1m 41s`、`1h 15m` | `apps/web/src/lib/format-duration.ts` 的 `formatDuration` |
| 时长（测量值） | 不足 1 秒 `850ms`，不足 1 分钟 `2.5s`，之后同上 | `apps/web/src/lib/stats-format.ts` 的 `formatDuration`，一分钟以上调用上一行 |
| token 数 | `850`、`2.3K`、`1.2M`（大写单位） | `formatTokens` |
| 计数 | 千分位 `11,711` | `formatCount` → `lib/i18n/format.ts` 的 `formatNumber` |
| 比例 | `84.2%`，整数不带小数 | `formatPercent` |
| 速度 | `42.6 token/s` | `formatSpeed` |
| 不可得 | `—`，不写成 0（统计页：「缺失的指标显示为「—」，不是 0」） | `UNAVAILABLE` |
| 相对时间 | 列表里的窄列：「刚刚」「5 分钟」；句子里：「刚刚」「5 分钟前」；Git 面板 `6m ago`、`yesterday` | `lib/i18n/format.ts` 的 `relativeTime`（窄列）、`timeAgo`（句子）；`gitTimeAgo` |

- 并列的元信息用间隔号：「已处理 · 1m 41s · 2.3K tokens」。
- 变化中的数字用等宽数字（[基础](foundations.md) §2.4）。
- 带 `~` 的数字是预估值，用 `fg-4`。
