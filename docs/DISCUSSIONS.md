# Riffet 侧边聊天

日期：2026-11-05。范围：服务端与 Web。原生客户端本期仅保持协议兼容。

用户选中回答中已经输出的片段，在主会话旁打开独立讨论。讨论使用选中片段和主会话的上下文，可连续追问并保存历史。主会话保留草稿和阅读位置，运行中的任务继续执行。

## 交互

- 现有选区工具栏增加「侧边聊天」，打开来源预览和独立输入框；首次发送问题时才创建会话并调用模型。
- 右侧非模态浮窗，不改变主会话宽度、不加遮罩。默认宽 400 px，新聊天高 320 px，已有聊天高 560 px，均受可用区域约束；右上角可放大至 560 px 宽和区域内完整高度，再恢复大小。收起浮窗不停止生成、不删除记录。
- 浮窗复用主题的 elevated、subtle、文本和阴影变量；引文使用两行紧凑预览，展开后可滚动。移除侧栏竖线、引用竖线、独立宽度手柄和回合导航；嵌入输入框使用轻边框，不叠加卡片阴影。
- 不同片段可分别建立讨论。同一讨论中的后续提问沿用自己的历史。主会话标题栏可重新打开讨论列表。首次发送前每个主会话保留一个讨论草稿，重选片段保留已输入的问题。
- 来源片段可定位回主回答。回复的「带回主会话」把内容加入主输入框草稿，保留原有草稿，由用户发送。
- 草稿和未确认请求保存在浏览器当前标签页的 sessionStorage；已发送问答与来源快照保存在 Riffet 服务端。旁路不参加快速对话的定时归档。

## 执行和上下文

复用 `backendId: chat` 的流式请求、按会话调度、停止、Run、journal 与 JSONL 历史。快照只包含可见问题和助手正文，不复制工具输出、推理记录和附件二进制。旁路运行在既有 quick-chat 系统项目中，`origin.kind: discussion` 指向主会话；来源关系与运行目录分开。Web 快速对话列表排除旁路，旁路从主会话打开。

新建聊天默认继承主会话的 provider / profile、模型和 effort。模型选择器仅列出同一 provider / profile 下的模型，允许修改模型与 effort；已发送聊天也可在空闲时调整，下一轮使用新配置。已有聊天不随主会话后续改动自动切换，新的聊天继承主会话最新设置。provider 范围由服务端创建和配置接口共同校验，不能通过客户端参数切换。

Claude Code、Codex 和 DSH 复用 chat 后端调用原 profile 的网关。集成模型源沿用原地址、认证命令和请求头。凭证留在服务端。

Cursor、Antigravity、Pi、Droid 和 TRAE CLI 用主会话的 Agent 和 profile 回答侧问。每轮传入冻结的来源快照和侧聊问答。停止侧聊只取消本轮回答。删除侧聊时，服务端也会回收该会话的后台摘要进程。

- Antigravity 要求主会话的提供方或模型源已配置 Gemini API Key。原生 Google 登录只用于主会话。
- Pi 和 Droid 的同一份配置可连接多个提供方。侧聊在创建时固定模型与提供方；旧会话缺少可确认的选择时，服务端会报告提供方不可用。
- TRAE 使用原生侧问 `turn/btw`。主会话绑定专属路由时，侧聊保留该绑定；解绑、替换或离线后会提示不可用。

Responses 的 effort 按原值发送，包含接口支持的 none、minimal、low、medium、high、xhigh、max；Anthropic 侧边聊天使用 adaptive thinking 与 `output_config.effort`。集成模型源只提供目录声明的档位，并保留当前已选值；显式 API 网关未声明档位时提供协议级选项。兼容网关是否支持相应模型参数仍以服务端响应为准，不静默降级。

主会话未保存模型时，优先读取最近实际派发的配置，再读取同 provider 的默认值；无法确定 provider 的历史聊天拒绝创建。模型目录未列出当前选择时，保留当前模型和 effort。模型请求仅跟随同源且保持 POST 的 307/308 重定向，自定义认证头和会话正文不得发送到其他源。

首次有效请求在服务端解析来源消息并冻结上下文，截止到选中回答所在轮。完整选中片段单独保留；上下文优先保留本轮用户问题和回答，再加入预算内的早期对话。超长材料按预算裁剪，超长选区显式拒绝，不能静默截断选中内容。无法验证来源时拒绝创建并保留客户端草稿。

每轮请求由旁路规则、固定来源快照、选中片段和旁路问答组成。快照是参考资料，其中的任务、计划、审批和工具调用不构成旁路指令。主会话后续内容不自动加入快照；旁路也不自动向主会话投递内容。

来源快照进入现有 session blob 存储，并随 Session、首条 Run 在同一事务中提交。Session 仅携带 blob 引用及来源锚点，避免每次列表刷新搬运整个主历史。可见时间线只包含旁路自己的问答。历史重建不能删除来源快照。

## 接口和数据

`POST /api/sessions/:id/discussions` 接收 `clientSessionId`、`commandId`、`text`、可选 `model`、`anchor: MarkAnchor` 和 `quote: MarkQuote`，返回 `{session, run}`。后续消息复用普通发送与取消 API，同 provider 的模型调整复用 native/model API。`GET /api/sessions/:id/discussions/models` 返回来源或已有侧边聊天的默认模型、同 provider 模型目录和参数。`GET /api/sessions/:id/discussions` 返回该主会话的讨论。

Session 的 `origin.discussion` 保存锚点、引文、捕获时间、上下文 blob 引用和请求指纹。选区复用收藏已有的 exact、prefix、suffix 与消息身份，位置只是提示，不创建收藏。

相同创建 ID 与相同请求返回第一次回执，后续主历史或模型设置变化不重新采集快照。相同 ID 改问题、模型或来源返回冲突。客户端在提交前持久化原请求，网络结果未知时只能核对或重试原请求，不能另造 ID 重发。

## 实现边界

- Web 在 `MarkLayer` 增加选区动作，`NativeSession` 只负责面板开合与主草稿回填。
- `SideDiscussion` 面板复用 `useSessionSync`、`TranscriptView`、`Composer`，使用独立 Session ID、草稿 key 和错误状态；不能调用主会话的发送或停止回调。
- 选区操作覆盖已完成及流式生成中的助手正文；嵌套旁路不开放。代码、列表和跨段选择沿用当前浏览器选区能力。选择期间暂停该段 Markdown 的重绘和会话行重新分组，避免后续工具输出将选中回答移入过程区时卸载 DOM；SSE 与模型生成继续，清除选区后显示最新文本。代码块异步高亮和数学渲染也延后到选区释放。流式高亮保留回合身份和原文快照，完成后按身份与文本重新定位。
- 服务端从已提交历史中找不到选区时，读取当前 journal 各实体的最新版本，包括仍在输出的 draft；已结束轮次遗留的 draft 不作为新的讨论来源。已创建讨论继续使用原快照。
- 普通 fork 的续作简报和自动导航不用于旁路。聊天源记录和上下文读取机制可以复用，旁路有自己的截止边界与指令。

## 插件 Agent

提供 `AgentBackend.streamDiscussion(host, profile, request)` 即可接入。插件用给定 profile 回答，保留原生模型参数。请求携带纯文本历史、系统说明、取消信号和输出预算。实现须隔离工作区、工具、扩展和主会话，并在结束、报错或取消时回收本轮资源。插件停用会打断该插件正在进行的侧聊。

## 验证

复用现有核心测试，扩展代表场景：父子会话隔离、上下文截止、同请求重试、副作用次数、快照持久化与重建、来源不可用、独立取消和归档策略。执行 TypeScript 检查、契约生成检查、受影响的历史与路由测试、Web 生产构建。UI 不新增快照或逐控件测试；实际界面验证边界在交付时记录。

首版网关验证：TypeScript、国际化、契约和错误文案生成检查、Web 生产构建通过；受影响的 7 个核心测试文件、118 个用例通过，覆盖 provider 隔离、同 provider 模型与 effort 调整、继承顺序、命令认证和请求头。重定向测试使用本地 HTTP 服务和虚拟凭证；模型网关测试使用模拟 SSE 响应。没有调用真实模型，也没有进行浏览器操作或原生平台构建。Web 构建保留现有 `::highlight` CSS 优化器及大 chunk 提示。

原生 Agent 验证覆盖了 Riffet 创建侧聊、继续追问和拒绝跨提供方的路由。Cursor 用已配置的提供方完成了真实问答。Antigravity、Pi、Droid 和 TRAE 使用真实 CLI 连接本地模拟模型服务，检查模型收到的上下文、工具限制和取消。

用户可见字符串自检：

| 文案 | 删除后缺失的信息 |
| --- | --- |
| 侧边聊天、关闭侧边聊天 | 功能和关闭图标的可访问名称 |
| 放大聊天、恢复大小 | 浮窗尺寸切换动作 |
| 回到原文、展开、收起 | 引文定位和完整预览动作 |
| 带回主会话 | 回复将进入哪个输入框 |
| 选中回答中的文字开始聊天 | 空状态下一步 |
| 主会话模型 | 模型尚未解析时的默认来源 |
| 无法发起侧边聊天、重试 | 失败对象和恢复入口 |
| 无法保存待发送消息，请检查浏览器存储空间 | 拒绝发送的原因 |
| 发送结果待确认，原请求已保留。、核对并重试 | 可能已发送，重试将核对原请求 |
| 选中内容过长，请缩小范围 | 选区限制及恢复方式 |
| 无法定位原文，请重新选择片段 | 来源验证失败及恢复方式 |
| 侧边聊天的上下文快照已不可用 | 后续问答不能继续的原因 |
| 当前会话的模型提供方暂不支持侧边聊天 | provider 无法直接调用时的原因 |
