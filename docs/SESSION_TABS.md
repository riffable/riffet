# Riffet 会话标签页

日期：2026-11-05。范围：Web 桌面端与服务端。手机布局不显示标签栏；原生客户端本期只保持协议兼容。交互原型：`docs/design/session-tabs-demo.html`。

## 样式与设置

- 设置 → 外观 →「标签页与视图」（见下文）：标签样式为关闭（默认）/ 标题栏 / 独立一行，三张缩略图选择。偏好存在浏览器本地，按服务端地址区分。
- 标题栏：标签栏占据主区原来的标题行（52 px）。当前标签用圆角底面和轻微阴影突出；浅色沿用 `bg-elevated`，深色将主题前景以 12% 混入 `bg` 得到选中底色。其余标签文字 `text-fg-2`，悬停出现 `bg-hover`。每个标签都预留 1 px 透明边框，状态变化不移动排版。
- 临时标签保留虚线边界，保留标签不描边；选中状态由底色和字重表达。未选中的临时标签只有一圈淡虚线、没有底色。首页的「新会话」标签使用保留的当前标签外观。
- 独立一行：标签栏放在主区卡片上方的画布上（顶部留 8 px，标签高 36 px，下沿与卡片上沿相接），保留当前标签原有的顶部圆角和底部两侧外凹轮廓。浅色沿用内容区底色；深色使用增强的选中底色，底部渐变回内容区底色，与两侧凹角连续衔接。仅临时标签以 1 px 虚线沿上沿、两侧和凹角绘制边界；卡片内不再有标题行，右侧栏从卡片上沿开始。
- 关闭：保留现在的「项目 / 标题 · 状态」标题行。
- 三种样式右侧都是：会话信息、右侧栏、⋯；视图切换选「标题栏图标」时排在最前，以分隔线隔开（当前视图 `text-fg`，其余 `text-fg-4`，没有底色）。需要用户处理的临时状态（连接失败、加速失败、等待终端操作、待恢复）出现时显示在会话信息左侧，平时不占位。

## 视图切换

- 默认「底部圆点」：会话区底部一条 24 px 的底栏，各视图共用同一个元素（带 key，切换视图不重新挂载）。未选中为 6 px 圆点，当前为主题色胶囊；悬停或聚焦展开为带名称的小药丸，Tip 显示快捷键 ⌥⇧1–3。
- 位置以对话视图阅读栏（输入框）的中线为准：右侧有大纲栏时阅读栏偏左，偏移量在对话视图测得后沿用到终端、画布，并跨会话保留，切换视图或标签时圆点不动。页面载入后的第一次放置等会话组装期（`ASSEMBLY_MS`）结束再淡入，不出现滑动；以终端或画布打开的会话直接居中显示。只有大纲栏出现或消失时圆点才平滑移动。
- 终端视图的工具栏不再为浮动切换器留空。手机与快速对话没有切换器，手机仍从菜单切换视图。

## 浏览器标签标题

Web 标签切到后台时，标题前的 `(n)` 只统计当前侧栏「只看未读」能列出的已结束、失败或中断的未读会话。每个会话算一条。数字随侧栏的服务器范围、标签与归档项目筛选更新，折叠分组或滚动列表时仍按筛选后的完整列表计数。待确认会话沿用会话上的待确认标记。切回前台或计数归零时隐藏数字。

离开前已有的未读也计入。在其他标签或设备读过结果后，数字随会话列表同步减少。会话归档时退出计数。旧服务器缺少已读记录时视为已读。

Mac：W，会话使用共享已读记录，浏览器标题计数由 Web 显示。

### 多服务器

- 标题统计的是工作台中的会话（A 类）。默认范围「本机与本机发起」包含本机会话与经本机发起的对端会话。「仅本机」「全部服务器」与单台对端按侧栏所选范围生效。选中范围外的会话时，临时显示的那一行只影响侧栏。
- 会话所在服务器和全局唯一 ID 随现有合并列表确定。对端离线时沿用工作台已同步的列表。标题从该列表计算，复用现有协议与缓存。
- 「全部标为已读」继续按所选服务器范围，经现有请求层发给会话所在的服务器。对端只接收当前工作台已列出的会话 ID，离线对端跳过。

## 标签

- 标签 = 打开的会话。侧栏仍是全部会话；标签只是快捷入口，关闭标签不停止、不归档会话。
- 标签左侧是 Agent 图标，运行中换成 spinner；右侧位置使用侧栏的待确认和已结束未读状态，结果在任一设备读过后随同步清掉。悬停或选中时换成 ×。
- 打开会话时（设置，仅保存在本机，标签关闭时不可选）：
  - 临时标签（默认）：任何途径打开一个未打开的会话（侧栏、⌘K、搜索、通知、深链）都作为临时标签，替换现有临时标签。发消息、会话开始运行都不会保留它；只有显式操作才保留：⌘ 单击、双击标签、「加入标签栏」（侧栏菜单、标签右键菜单）。
  - 直接加入：新打开的会话立即成为保留标签，不再有临时标签。
- 新建会话时（设置，仅保存在本机；标签关闭或「打开会话时」为直接加入时不可选）：由 Riffet 新建或派生的会话：
  - 直接加入（默认）：打开时即为保留标签。
  - 临时标签：和打开的会话一样，作为临时标签打开，只有显式操作才保留；打开别的会话时它被替换。
  - 无论哪种模式，在后台开始运行的会话（定时、唤醒）都不会自动加入标签：标签只在会话被选中时产生。
- 置顶会话（`pinnedAt`）的标签固定在左侧置顶区，与普通区之间有分隔线；置顶区最多占 45% 宽度，再多在区内滚动。置顶标签同样可以关闭；再次打开时回到置顶区。置顶一个已打开的会话，它移入置顶区，临时标签仍是临时的；置顶不会自动打开标签。
- 拖拽只在同一区内排序，跨区拖放无效；靠近两端时该区自动滚动。普通区顺序存在本地；置顶区顺序就是服务端置顶顺序（见下）。
- 横向滚动：触控板原生，鼠标滚轮转为横向。放不下时两端渐隐，并出现 ⌄ 列出全部标签。
- 宽度像浏览器标签栏：每个标签最宽 320 px，放得下时都按最宽显示；放不下时普通区收缩到剩余空间，标签平分宽度，当前标签不小于 200 px、其余不小于 88 px，再多则横向滚动。标签不显示项目名，项目只在信息卡与 ⌄ 列表中出现。
- 打开的标签从零宽展开、关闭的标签收拢后移除，普通区总宽度同步过渡（约 200 ms），邻近标签平滑让位或补位；「减少动态效果」时不做动画。
- 悬停 600 ms 显示信息卡：标题、项目（worktree）、分支、状态；运行中的会话加一句「关闭标签后仍在后台运行」。
- 右键：置顶/取消置顶、重命名、关闭、关闭其他标签、关闭右侧标签；临时标签多一项「加入标签栏」。中键关闭。
- 侧栏会话行的 ⋯ 菜单：「加入标签栏」（不打开该会话；它已是临时标签时变为保留）/「移出标签栏」（关闭它的标签，规则同关闭）。标签关闭或手机布局时不显示。
- 关闭当前标签切到右侧相邻标签，没有则左侧，都没有回到项目首页。重开刚关闭的标签回到原位置。
- 「+」与项目首页：首页显示时有一个临时的「新会话」标签；首页创建的会话替换这个标签。
- 统计、任务、收藏、扩展等页面打开时，标题栏样式隐藏标签栏；独立一行样式保留标签栏、不选中任何标签。
- 归档或删除的会话从标签中移除。

## 会话信息浮窗

- 按钮使用线性 Info 图标（⌥I）；子 Agent 或后台任务在运行时右上角显示一个小点。
- 头部最重：Agent 图标块、标题（最多两行）、状态行（运行中 · 已持续时间 / 空闲 · 最近活动），有会话标签时列在下方。
- 属性两列对照：模型（含推理强度等取值参数）、权限（后端命名）、上下文（细条与用量、费用）、目录（项目名与路径，点按复制）、分支（点按复制）、创建时间；没有的项不显示。
- 前往：变更（+N −M）/ 文件 / 终端（⌃`）三行，轻于上方信息。
- 动态：侧边聊天、子 Agent、后台任务、本会话收藏，各一组，没有内容的组不显示。
- 手机标题面板复用同一组件（隐藏头部，由面板自己的标题代替），不再有单独的信息行列表。
- ⋯ 菜单保留会话操作：重命名、编辑标签、置顶、分享、交接、存为模板、恢复、加速、归档等。

## 侧栏排序

- 显示选项新增「排序」：最近活动（默认）/ 按标签页顺序。标签页关闭时不显示后者。
- 按标签页顺序只改变置顶会话的排列：使用服务端置顶顺序，即在置顶时间（新置顶在前）的基础上叠加标签栏里的拖动调整。普通会话保持最近活动排序，避免打开标签时侧栏行在光标下移动。

## 设置页：标签页与视图

外观组内，排版之后；页面只有一句「仅保存在这台设备」，命令面板的设置入口由 `settingsSections` 自动带上。从主题页移来了标签样式缩略图。

- 标签样式：关闭 / 标题栏 / 独立一行。
- 打开会话时：临时标签 / 直接加入；标签样式为关闭时不可选。
- 新建会话时：临时标签 / 直接加入；标签样式为关闭或打开会话时为直接加入时不可选。
- 视图切换：底部圆点 / 标题栏图标。
- 显示的视图：视图目录里当前可用的会话视图（对话、终端，以及已启用插件的视图，如画布），按当前顺序排列，每行有上移、下移和显示开关；对话的开关锁定为开。顺序和隐藏按视图 ID 存储，停用插件的视图不显示，但它的位置保留，重新启用后回到原位（见 [PLUGIN_ARCHITECTURE.md](PLUGIN_ARCHITECTURE.md)）。
- 快捷键：见下表，Apple 平台为 ⌥，其他平台为 Alt。表是 `packages/contracts/src/shortcuts.ts`，改键在设置「行为 › 快捷键」（标签 1–9 的整组键只读）；按键处理在 `use-global-shortcuts.ts`。

## 快捷键

⌥（Windows 为 Alt），按 `event.code` 匹配；焦点在终端或输入法组字时不响应。⌘/Ctrl 与 T、W、Tab、数字被浏览器占用，⌃W 在终端里是删词。

| 操作 | 快捷键 |
| --- | --- |
| 第 1–8 个 / 最后一个标签 | ⌥1–8 / ⌥9 |
| 前一个 / 后一个 | ⌥[ / ⌥] |
| 关闭标签 | ⌥W |
| 重开关闭的标签 | ⌥⇧T |
| 新会话 | ⌥T |
| 会话信息 | ⌥I |
| 切换视图 | ⌥⇧1–3 |

## 接口和数据

- `Session.pinRank?: number`：置顶顺序，小的在前。置顶时服务端赋值为现有最小值减一（没有已排序的置顶会话时不赋值）；取消置顶时清除。排序规则：都有 `pinRank` 按其升序；只有一方有时无 rank 的在前；都没有按 `pinnedAt` 降序。
- `PUT /api/sessions/pin-order`，`{ sessionIds: string[] }`：按给定顺序把 `pinRank` 写为 0..n-1。只接受当前已置顶、未归档的会话，未列出的置顶会话保持原值；同一请求重复提交结果相同。每个变化的会话追加 session 事件。
- 打开的标签、普通区顺序、预览标记、样式与打开方式偏好只存在浏览器本地；首版不做多个会话常驻挂载：切换标签时对话按会话重新挂载，会话页框架保持不动（[界面](design/system/surfaces.md) §1.1）。

## 实现边界

- `app/tabs/chrome.ts`：`TabChromeContext`，标签栏提供给页面头部的动作插槽。头部在该上下文存在时不画自己的标题行，把动作 portal 进插槽；有 `center` 内容的首页头部只保留居中内容一行。
- 标签状态订阅导航状态：`nav.sessionId` 变成未打开的会话时按预览规则加入，不逐个改动导航调用方。
- 文案按 `AGENTS.md` 与全局 UI 规则留白；`.po` 文件统一在集成时提取。
