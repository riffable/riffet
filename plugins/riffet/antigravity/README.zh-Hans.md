在 Riffet 里运行 Antigravity（`agy`）会话。每个会话对应一个 `agy` 终端界面，Riffet 读取它的本地记录和状态来显示对话，终端和对话视图是同一个会话，可随时切换。

## 准备

- 在服务器上安装 Antigravity CLI（`agy`）并登录。使用 Google 登录的提供商沿用 CLI 自己的登录与配置。
- 也可以在「模型提供商」里添加 Antigravity 提供商，填写 Gemini 协议的服务地址和 API Key。Key 保存在服务器上，只通过环境变量交给 CLI。

## 配置

- Antigravity 提供商：CLI 路径、服务地址与 Key、开放的模型，以及是否允许 CLI 自动更新（默认关闭）。修改后在会话空闲时生效：Riffet 重启终端界面并接回同一个对话。
- 填了服务地址或选了模型源时，模型列表来自该网关；否则来自 CLI。
- 新建会话时，在 Agent 列表里选择 Antigravity。

## 数据与限制

- 每个会话在插件数据目录下有自己的私有配置目录，不复制登录状态，也不改你自己的 `agy` 设置；用户目录里的规则、技能、MCP 和 hooks 配置会作为快照带入。
- 依赖 `agy` 1.5.x 的私有格式，未验证的版本可能只能在终端里使用。
- 审批和单选提问可在任一视图回答；多选、自由文本、登录等涉及秘密输入的场景需要在终端处理。
- 停止和运行中追加消息不能精确指向某一次执行。

关闭插件后不能再新建 Antigravity 会话。
