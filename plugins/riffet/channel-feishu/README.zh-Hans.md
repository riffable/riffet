在飞书或 Lark 里和 Riffet 的会话对话。私聊或群里给机器人发消息，Riffet 会在该聊天选定的项目里新建或继续会话，把思考、工具调用和回答实时写回一张卡片。审批和提问可以直接在飞书里回答，在飞书发起的会话与其他客户端保持同步。

## 准备

- 服务器需要能主动连出飞书或 Lark，不需要公网地址。
- 用飞书或 Lark 客户端扫码创建机器人：Riffet 直接拿到 App ID 和 App Secret，并绑定扫码的人。也可以手动填写已有应用的 App ID 和 App Secret。
- 同一个应用只能有一个 Riffet 实例连接；多个连接会被飞书分摊事件，表现为丢消息。

## 配置

- 「设置 › 机器人」列出机器人、连接状态和待完成的检查项：应用启用、权限（附申请链接）、收到第一条消息。
- 只有绑定过的飞书账号能使用机器人，其他人的消息忽略。绑定用设置里生成的一次性绑定码（5 分钟有效），在飞书私聊机器人发 `/bind <码>`；扫码创建的机器人会自动绑定扫码的人。
- 聊天命令：`/new`、`/stop`、`/project`、`/status`、`/flat on|off`（群）、`/bind <码>`。其余以 `/` 开头的消息原样交给会话。

## 群聊与会话

- 群里 @ 机器人开始会话，每个话题是一个独立会话。已绑定会话的话题里，绑定用户不用 @；这需要读取群内全部消息的权限，没有该权限时话题里也要 @。`/flat on` 让整个群共用一个会话。
- 每个聊天绑定一个项目，首次使用时选择，用 `/project` 切换；不能在飞书里新建项目。
- 其他客户端发起的回合也会发到同一话题里，并标明来自其他客户端。

## 数据

App Secret 保存在服务器的私有文件里，不会返回给客户端，设置里只显示是否已配置。你发送的图片和文件由服务器下载并作为附件加入会话（每条最多 20 个，单个 24 MB）。

关闭插件后机器人断开连接，机器人和聊天记录保留，重新开启后自动恢复。
