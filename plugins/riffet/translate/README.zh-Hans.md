在回答的更多菜单和选中文字时的工具条里加一项「翻译」，译文显示在这条回答下方或选区旁。

- 译成的语言在本页选择，默认跟随界面语言；回答本来就是这种语言时改译成英文（界面是英文时译成简体中文）。
- 使用「设置 › 辅助模型」里为「翻译」选择的模型；没有单独选择时用辅助模型的「默认模型」。消息会发给这个模型的提供商。两者都没有选择时，翻译会提示先去选择。
- 代码块、行内代码、路径、命令和链接保持原样。
- 译文只在打开这个会话期间保留，不写入会话，也不同步到其他设备。服务端在内存里留一份最近的译文供重复翻译时直接返回，关闭插件时清空。

这个插件也是「消息菜单」和「选区菜单」扩展点的参考实现：manifest 里一条带 `menus: ['message', 'selection']` 的命令，处理函数读取 `context.message` 或 `context.selection`，返回 `{ kind: 'text' }`，没有客户端代码。它也是「模型用途」（`modelUses`）的参考：声明一项用途，调用时带上 `use`。见 [插件架构](../../../docs/PLUGIN_ARCHITECTURE.md)「消息菜单」。
