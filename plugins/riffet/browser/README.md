Lets the Agent open pages, read them, click and type in a browser Riffet hosts. The browser runs on the server; its picture is live in the conversation's Browser panel, and you can use it yourself at any time.

## Using it

1. In Settings, choose the browser: download the Chromium Riffet uses, or use Chrome or Edge installed on the server.
2. In the composer's Skills & tools, select Riffet Browser.
3. The browser starts on the Agent's first browser tool call; open the Browser panel to see the page.

## Working together and confirming

- Click, scroll or type in the panel whenever you like; it does not interrupt the Agent, which learns on its next step that you used the page and reads it again.
- Sending, submitting and deleting are confirmed in the panel first, except on local addresses and the sites that need no confirmation. Orders are always confirmed, and payments are always left to you.
- When a page needs you, such as a sign-in or a captcha, the Agent says so in the panel; press Done when you have finished and it goes on.

## Data

- Each project has its own browser profile (cookies, sign-ins, cache), kept on the server. Clear it per project in Settings.
- Page content reaches the Agent as untrusted data, never as instructions.
- Turning the plugin off closes every browser; the profiles stay.

## Agent tools

`browser_open`, `browser_snapshot`, `browser_act`, `browser_screenshot`, `browser_tabs`, `browser_inspect`, `browser_handoff`
