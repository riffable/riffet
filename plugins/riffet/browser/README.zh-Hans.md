让 Agent 在 Riffet 托管的浏览器里打开网页、读取内容、点击和输入。浏览器运行在服务器上，画面实时显示在会话的「浏览器」面板里，你也可以随时直接操作。

## 使用

1. 在「设置」里选择浏览器：下载 Riffet 使用的 Chromium，或使用服务器上已安装的 Chrome、Edge。
2. 在输入框的「技能与工具」里选中「Riffet 浏览器」。
3. Agent 第一次调用浏览器工具时启动浏览器，打开「浏览器」面板即可看到页面。

## 一起操作与确认

- 你可以随时在面板里点击、滚动或输入，不会打断 Agent；它下一步会知道你操作过页面，并重新读取。
- 发送、提交、删除这类操作，除本机地址和「无需确认」的网站外，会先在面板里请你确认。下单总会先确认，付款总由你完成。
- 遇到登录、验证码这类需要你处理的页面，Agent 会在面板里说明，你做完点「完成」，它接着进行。

## 数据

- 每个项目使用一份独立的浏览器资料（Cookie、登录状态、缓存），保存在服务器上，可以在「设置」里按项目清除。
- 网页内容以不可信数据交给 Agent，不作为指令。
- 关闭插件会关闭所有浏览器，资料保留。

## Agent 工具

`browser_open`、`browser_snapshot`、`browser_act`、`browser_screenshot`、`browser_tabs`、`browser_inspect`、`browser_handoff`
